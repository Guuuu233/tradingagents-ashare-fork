## 1. 项目竣工定义（对齐 David 的核心哲学）

**不是"功能越多越好"，而是三条线全部闭合：**

1. **诚实校准闭环**：系统能对历史报告做命中率/可靠性统计（"说 60-70% 上涨概率的，实际命中多少"）——这是项目立项的初衷（宝妈指数 → 命中率验证）。
2. **数据诚实无漏洞**：任何数据源失败都显式报告，绝不静默造假；历史日期分析严格防前视。
3. **稳定可用**：一次分析不因服务重启/模型抖动而中断；输出全中文；报告结构完整。

## 5. 施工纪律（延续 AGENTS.md + 交接书）

1. **读完再改**：改任何文件前先读全文件 + grep 调用点。
2. **改原路径**：禁止 _v2/_new/_fixed 并行实现；删死代码。
3. **一次一提交**：一个 commit 一个关注点；不自行提交主分支（David/Hermes 确认后）。
4. **TDD**：bug 修复先写复现测试（RED→GREEN）。
5. **环境铁律**：所有 Python 命令必须 `env -u PYTHONPATH`；测试用 `.venv310/bin/python -m pytest`。
6. **不造假**：数据失败显式报告，绝不填 0/空串。
7. **完成汇报自动触发调度**：每完成一小段，在 issue 评论 @项目调度助手 触发下一轮。
