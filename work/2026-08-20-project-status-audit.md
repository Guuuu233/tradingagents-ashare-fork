## 三、核心问题诊断

### 问题1：Prompt 增强已完成，但**数据层缺失**

Prompt 现在要求分析师做"上游成本传导"、"下游需求传导"、"国际对标"，但：
- DataCollector **不采集** LME铜价、三星电子股价、碳酸锂价格等指标
- 分析师**看不到**产业链数据，只能空谈

**类比**：给了厨师一份详细菜谱（Prompt），但厨房里没有食材（数据）

---

### 问题2：知识库是孤岛

虽然有 27 个行业图谱 + 19 个宏观情景，但：
- 知识库是静态 markdown 文档
- DataCollector **不读取**知识库
- 分析师 **看不到**知识库内容

---

### 问题3：7个分析师仍是并行孤岛

当前架构（`setup.py:245-252`）：
```
data_ready → [macro, fundamentals, news, sentiment, market, smart_money, volume_price] → Bull/Bear
```

**问题**：基本面分析师写报告时，**看不到**宏观分析师的"原油上涨10%"
