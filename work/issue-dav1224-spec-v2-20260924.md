## 施工内容

按单关注点提交，依次为 C1 → C5，放在同一个实现分支上。

### C1 抽取假阳性（对应 W1 第一部分）

- **数字边界**：禁止正则回溯截断。典型错例：「900亿元」被抽成 90；「10日」被抽成 1；「89.09%」被抽成 89.0。
- **非价格单位与语境**，不生成价格坐标：
  - 亿、万、%、倍、股、手、日、月、年、季、bp、pct、点，包括数字与单位之间有空格的写法；
  - 日期和年份；
  - Markdown 列表序号；
  - JSON 及机读块片段。
- **外币与境外标的报价**（美元、港元、美股、COMEX、WTI 等）：不生成 A 股 price_ref。
- **每股财务指标**（每股净资产、EPS 等）：不作为价格坐标。

### C2 typed disclosure 与转换语义（对应 W1 第二部分）

- **判定对象**是「这个数值是不是该类披露价」。以下情形都不算对应的披露价：
  - 大宗商品、原材料、大宗成本，不等于大宗交易；
  - 交易计划或资金流中的增持、减持，不等于股东增减持；
  - 票据、中票、股本、发行成本，不等于发行价；
  - 逆回购不等于回购；
  - 回购语境中出现的本标的坐标价，不等于回购价。
- **他标的的发行价**：单列为 `other_symbol`，不进入本标的的坐标体系。
- **invalid_conversion**：只有出现价格口径转换语义（复权、前复权、不复权、因子、除权）时才成立。估值算术中的「折合」「折算」「对应」，不再视为口径转换。

### C3 derived_estimate 语义角色（对应 W2）

- **判定必须绑定到数字本身**：在同一子句内、该数字之前约 25 字内，出现估值算术强词，才算 derived。强词包括 PE、PB、市盈率、市净率、估值、折合、折算、测算，以及「对应股价 / 对应每股 / 对应市值」等。
- **弱词不得单独触发**：「假设」「情景」「悲观」「乐观」「防御」「底线」。
- **真报价保护**：带报价语义、且与本次运行的具名字段同值的数字，不得降为 derived。
- **derived_estimate 的处理规则**：
  - 不承担 decision-driving 的 basis / as_of 问责；
  - 不得作为 executable level 的依据；
  - 不参与跨口径坐标混用的判定；
  - 保留 lineage。

### C4 共享可执行价位解析（对应 W3）

- **共用词表**：registry 与 gate 共用同一份词表和解析函数。词表覆盖：目标价、目标位、止盈、止损、入场、进场、买入、卖出、建仓、开仓、出场、加仓、减仓。
- **区间**：两端都要处理，即「X–Y 元」中的 X 和 Y 都要解析。
- **伪价位过滤**：列表序号、百分比、数量、日期等。

### C5 严格 source-backed 桥接（对应 W4）

- **只允许字段级身份**，满足以下任一条件才可桥接：
  - 上下文明确写出指标名（EMA10、VWMA、SMA、BOLL 等），且数值与本次运行中对应指标精确相等；
  - 明确的日期加 OHLC 字段；
  - 明确的涨跌停字段。
- **仅数值相等**，不得继承 vendor_qfq。
- **provenance** 记为 `pool_bridge:<field>`。
- **数据来源**：桥接用的数据取自本次运行的 state，即 as-of trade_date 的行情与指标。不得访问外部数据或未来数据。
