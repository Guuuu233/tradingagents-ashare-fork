# 请项目评估师对《全系统代码终审与统一优化实施规划》进行独立评估与风险把关

## 背景与规划概要
团队已完成对系统 4 大领域（API/后端、多智能体图引擎、数据流适配器、前端实时交互）的全面代码审查。现规划分 5 大模块进行加固与优化：
1. **多智能体流式管道与图状态一致性**：统一各节点 astream/invoke 回退与 token emit 机制，剥离思考草稿；
2. **数据层异常捕获与长连接防护**：加固 Tushare/东财/同花顺连接池回收与类型化错误分类；
3. **API 路由与数据库并发安全**：优化 SQLite WAL busy_timeout，消除连接悬挂隐患；
4. **前端 SSE 实时消息状态机与防抖**：双周期辩论消息隔离 `${debate}:${horizon}` 复合 key，校准度输入防抖；
5. **代码卫生与冗余清理**：清理死代码、未用 import 与历史废弃文件。

## 评估与审查要求
请从**架构风险、代码树冲突、回归风险、施工优先级与可行性**四个维度进行深度评估：
1. 识别上述方案中是否存在过度设计、破坏既有稳定契约（如 3000 字提示词、fail-closed 资金流门禁）的风险点；
2. 对 4 个并行施工泳道的边界与依赖解耦给出调整建议，确保不发生 git conflict；
3. 提出需要补充的边界测试或安全防御措施；
4. 产出最终评估报告与优化修订建议。
