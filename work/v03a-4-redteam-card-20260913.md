# DAV-863：V-03a 候选 RT 覆盖面与证据边界复核

## 任务性质

这是 DAV-862 候选交付后的独立、只读红队复核。目标是检查候选是否真正覆盖 V-03a 冻结协议的红队场景，并核对交付证据是否足以进入代码审查。

候选对象固定为：

```text
candidate: c36fbc525355a880835db8c43d65fc445b6bdc95
parent:    7cd1a8523e5f879712739576d7b6f101f2c1ff2c
trunk ancestor: a227cdc3bb466edf2e910419cb6013cfc021d309
remote: origin/agent/1/01a09942
worktree: DAV-862 candidate worktree
```

不得改代码、不得补测试、不得提交、不得 FF、不得部署、不得启动服务、不得写生产库。发现缺陷时只写报告并指出路径/行号/证据。

## 复核范围

1. 读取 DAV-862 的完整交付评论、候选完整 SHA、直接父提交和白名单 diff；确认没有把 WIP、工作目录产物或其他 SHA 当成候选。
2. 对照 V-03 冻结协议和 DAV-862 验收标准，逐条检查 RT-1 至 RT-16：
   - 生产库与 SQLite 副本隔离、前后 hash/count/quick_check/integrity_check；
   - 单账号与 `status=completed` 范围，以及 cutoff 与 requested/as-of 区分；
   - 25 字段审计表、typed-missing、coverage 与 return 分母；
   - DEV / HISTORICAL_OOS / FORWARD_OOS 三段边界和六只回归标的隔离；
   - T+1 Open、不可执行入场、成本、沪深300基准；
   - 不由 confidence 推 probability，不输出 Sharpe / 最大回撤，不伪造收益结论；
   - 复制、顺序、缺口、命题四类消融，以及同快照、同资格、同成本、单变量变化；
   - purging / embargo 和重叠标签审计证据；
   - 当前没有 FORWARD_OOS 时如实输出 0。
3. 静态核对三条白名单路径的实现，重点找：
   - 生产库写入口或绕过 SQLite backup 的读取；
   - 默认值、carry-forward、静默 drop、把未知变成 0；
   - 平行收益计算路径、隐式日期回退、未记录随机性；
   - 把 regression 或历史样本伪装成 OOS；
   - 测试删除、重命名、改松或通过改硬编码掩盖失败。
4. 复核交付报告中的数字是否能由候选代码、测试输出和工作目录证据复现。`work/` 产物只作为本地证据，不能被算作代码提交内容。

## 测试核对

只读复核可重跑必要的定向检查；必须明确记录实际执行的命令、版本和精确结果。不得把未完成的全量测试写成通过，也不得把父版本已有失败写成候选新增缺陷。

至少核对：

- 父版本原有 17 个测试函数是否逐一保留、原断言是否未被弱化；
- RT-1 至 RT-16 是否是追加测试且确实执行；
- 候选与父版本全量失败集合是否有同口径证据；
- 离线 runner 是否无真实模型调用、无生产写入，且报告仍标记为“半成品基线，非定性判断”。

## 交付格式

只提交一条汇总复核报告，明确：

- 候选 SHA、直接父 SHA、实际审核范围；
- RT-1 至 RT-16 逐项 `通过 / 有缺口 / 不适用`，每项给证据或路径/行号；
- 发现按 HIGH / MEDIUM / LOW 分级；任何 HIGH 正确性、数据泄漏或测试造假问题直接建议打回；
- 是否允许进入下一步“代码审核员”只读审查；这不是合入、部署或准予上线。

本卡不得修改 DAV-862 的代码或测试，不得代替代码审核卡，也不得派给“独立代码审核员”。
