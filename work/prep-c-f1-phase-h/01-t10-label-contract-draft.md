# T+10 行业相对标签契约（草案 v0.1，未冻结）

> 适用成员：总控（审定）、阶段 H 执行者、数据层维护者。
> 相关链接：issue DAV-1228；协议 v1.0.1 §3、§10。
> 状态：**草案，未经总控审定不得冻结**。本文件只填协议 §10 要求的「T+10 标签契约」一项。

## 0. 标签语义

与协议 §4.3 概率语义同义：

`Y_i = 1` 当且仅当标的 i 的 T+10 价格相对收益减去其事件时所属行业基准的同期收益 > 0；否则 `Y_i = 0`。

## 1. 行业基准

| 条目         | 草案取值                                                         | 备注                                                                                                                                              |
| ------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 分类体系     | 申万一级行业（SW 2021 版）                                       | 与现有代码中静态 `申万` 行业标注口径一致（`target_pool.py`），便于对接                                                                            |
| 历史归属来源 | 事件日（首次年度业绩预告公告日）当日生效的申万一级归属           | **不得用现行分类回填**（协议 §3 硬性要求）。候选数据源见 `03-data-availability-audit.md` §C，目前无已接入的 PIT 归属源——这是阶段 H 的硬终止风险点 |
| 基准收益口径 | 同行业基准指数的价格收益（不含股息）                             | 申万一级行业指数点位序列；若 SW 指数不可得，回退方案为同季同事件样本内同行业成分股等权收益（需冻结时明示选择）                                    |
| 归属缺失处理 | 事件日归属无法证明 → 该事件剔除出阶段 H 合格集，计入排除原因统计 | 不得静默用现行归属替代                                                                                                                            |

## 2. 收益定义

| 条目      | 草案取值                                                                                    | 备注                                                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 事件日 T0 | 首次年度业绩预告的**公告日**；公告日在非交易日时，顺延至下一个交易日                        | 交易日历以 `trade_calendar.py` 的 A 股日历为准                                                                                                |
| 入场日    | T0 之后的第一个交易日（T+1 纪律，与 `return_labels.py` 的 strict T+1 entry viability 一致） | 若 T0 为交易日且公告在盘前，是否允许 T0 入场——**待确认项 T-1**                                                                                |
| 入场价    | 入场日开盘价（可执行口径）                                                                  | 备选：入场日收盘价（信息口径）。草案建议开盘价，与「截止时合法信息」语义一致                                                                  |
| 结算日    | 入场日起第 10 个交易日（T+10，交易日计数）                                                  | 日历同上                                                                                                                                      |
| 结算价    | 结算日收盘价                                                                                |                                                                                                                                               |
| 复权口径  | 入场与结算统一用同一口径：`vendor_qfq`（前复权）或 `pit_adjusted`                           | 现有 `return_labels.py` 已支持 `vendor_qfq / raw / pit_raw / pit_adjusted`；草案建议 `vendor_qfq` 用于标签计算，`pit_adjusted` 作为敏感性核对 |
| 相对收益  | `r_stock − r_index`，两收益同口径同窗口                                                     | `Y=1 ⟺ r_stock − r_index > 0`；等于 0 记 0                                                                                                    |

## 3. 停牌与退市处理

复用 `return_labels.py` 的 OutcomeStatus 7 态契约，标签层映射如下：

| 情形                          | 草案处理                                                                                           |
| ----------------------------- | -------------------------------------------------------------------------------------------------- |
| 入场日停牌（无法成交）        | 顺延至复牌后首个交易日入场，顺延上限 10 个交易日；超限 → `unexecutable_entry`，剔除并计数          |
| 结算日前停牌且复牌在窗口内    | 结算日顺延至复牌日；窗口总顺延上限 20 个交易日，超限 → `suspension`，剔除并计数                    |
| 结算日前退市 / 长期停牌不复牌 | `suspension`：剔除出 0/1 标签集，单独报告占比。**不得**把退市记为 0 或记为 1——两种做法都会污染基率 |
| 退市整理期内仍可成交          | 按可成交规则正常计算，但事件标记 `delist_risk` 供敏感性分析剔除                                    |
| 数据缺失 / provider 失败      | `data_missing` / `provider_failure`，剔除并计数，不得回填                                          |

所有剔除事件的 `opportunity_id`、剔除原因须落盘可审计。

## 4. 待确认项（冻结前需总控裁定）

- T-1：盘前公告日是否允许 T0 入场（草案默认 T+1 入场）。
- T-2：行业基准首选申万一级指数 vs 样本内行业等权，取决于 §C 可得性结论。
- T-3：停牌顺延上限（10/20 交易日）数值是否调整。
- T-4：北交所、ST/*ST 是否在事件合格集内（草案默认剔除 ST/*ST，待确认）。
