## A. 首次预告版本与公告时间戳

- **来源接口**：`tradingagents/dataflows/providers/cn_akshare_provider.py:6435` `get_earnings_forecast` → akshare `stock_yjyg_em(date=报告期)`（东方财富业绩预告池）。
- **PIT 可证性**：中等偏好。代码按 `公告日期 ≤ curr_date` 截断（`cn_akshare_provider.py:6515` 附近），公告时间戳字段存在且已被 PIT 纪律使用。
- **已知风险**：
  1. 「首次」判定：东财该接口按报告期返回记录，是否保留同一公司同一年报的多次预告行（首发 vs 修正）不确定 → **待单点探测**：取一个历史报告期（如 2023 年报，date=20231231）抽查有多次预告记录的公司，看接口返回行数与日期序列。
  2. 历史覆盖深度：东财预告池对早期报告期（如 2015 年前）的覆盖不确定 → 同一探测可顺带确认最早可用报告期。
  3. 备选补充：巨潮 `cninfo_disclosure.py` 已有公告检索管道（含 `category_*` 分类），可作预告公告时间戳的独立旁证源。
- **是否需新接入**：视探测结果；若东财不保留多版本，需用巨潮预告类公告按公司-报告期取最早公告日重建「首次」。

## B. 复权价格

- **来源接口**：akshare `stock_zh_a_hist(adjust="qfq"/"hfq"/"")` 及 `stock_zh_a_hist_tx`，接入于 `cn_akshare_provider.py:1039–1099`。
- **契约层**：`tradingagents/dataflows/return_labels.py` 已实现完整结算管线——`PRICE_BASIS_VENDOR_QFQ / RAW / PIT_RAW / PIT_ADJUSTED` 四种口径（`return_labels.py:63–67`）、strict T+1 入场、交易日历顺延、双侧停牌证据、7 态 OutcomeStatus。标签契约草案直接复用。
- **历史覆盖**：A 股日线全历史；**注意**：退市标的 symbol 能否在东财日线接口取到需单点验证（东财对退市股常返回空）。
- **PIT 可证性**：`pit_adjusted` 口径存在；`vendor_qfq` 为「以今天为锚的前复权」，用于历史标签时两口径差异可做敏感性核对。
- **是否需新接入**：否。

## C. 事件当时的行业归属与行业指数（协议 §3 硬终止项）

- **现状**：代码内行业信息只有 `target_pool.py` 的静态申万行业标注（候选池内嵌字符串，非 PIT、非全市场）。**无任何「某日期某股票的申万归属」数据源接入**。申万行业指数行情未接入（现有指数接入只覆盖大盘指数：`cn_akshare_provider.py:6823` 附近 `stock_zh_index_daily_tx/em`）。
- **候选来源**：
  | 来源                                                       | PIT 可证性                                  | 成本                                                | 备注                       |
  | ---------------------------------------------------------- | ------------------------------------------- | --------------------------------------------------- | -------------------------- |
  | Tushare `index_member`（申万成分）                         | 中：成分快照+变更记录，需验证历史回填完整性 | 积分制（具体权限门槛**待查**，通常需数千积分/付费） | 最可行候选                 |
  | akshare `index_hist_sw` / `sw_index_daily`（申万指数行情） | 指数行情可得                                | 免费                                                | 只解决基准收益，不解决归属 |
  | akshare `stock_board_industry_cons_em`（东财行业成分）     | **不可 PIT**：仅现行快照                    | 免费                                                | 不能用于历史归属           |
  | Wind / Choice / 申万官方                                   | 强                                          | 付费许可                                            | 需采购决策，超出本助手范围 |
- **结论**：行业归属是本盘点最大的结构性缺口，直接对应协议 §3 的硬终止条件「无法构建当时的行业归属与股票池」。建议优先对 Tushare `index_member` 做权限确认与单点探测。

## D. 当时的可投资股票池（含退市与长期停牌）

- **现状**：无历史全市场股票池快照。现有 `target_pool.py` 是静态候选名单，不是「事件日当时可交易全集」。交易日历完备（`trade_calendar.py`，akshare+fuyao 双源）；停牌证据机制存在于 `return_labels.py`（双侧停牌证据、顺延规则）。
- **候选来源**：
  | 来源                                                                 | 覆盖                       | 备注                                  |
  | -------------------------------------------------------------------- | -------------------------- | ------------------------------------- |
  | Tushare `stock_basic(list_status=L/D/P)` + `suspend_d` / `bak_basic` | 含退市股与停牌日记录       | 需积分；退市股日线可用 `bak_daily` 补 |

- **是否需新接入**：是。最小路径 = baostock（免费、已接入框架）做停牌/退市判定 + Tushare `stock_basic` 做历史在市名单交叉验证。

## E. 阶段 E 所需「事前卖方预期」——确认无接入

- **实证**：全仓检索 `report_rc`、`eps_estimate`、`consensus`、`一致预期`、`盈利预测`、`卖方预期` —— 生产代码零命中（命中仅为无关的 `fund_flow_consensus_guard` 测试字段）。`tushare_provider.py` 仅接入 `income` 利润表。总控初查结论**确认无误**。
- **候选来源**：
  | 来源                                                                                        | PIT 可证性                                    | 费用/权限                                        | 适配度                                                     |
  | ------------------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
  | Tushare `report_rc`（券商盈利预测明细）                                                     | 强：含报告日期、机构、预测值                  | 积分门槛较高（具体档位**待查官网**；属付费区段） | 字段结构最贴合 `consensus_median/coverage/dispersion` 需求 |
  | akshare `stock_profit_forecast_em` / `stock_profit_forecast_ths`（东财/同花顺盈利预测汇总） | 弱–中：多为当前年度快照，历史截面可得性不确定 | 免费                                             | **待单点探测**：能否取历史某日的当时预期值                 |
