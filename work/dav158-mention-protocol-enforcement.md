# DAV-158 完工 @项目调度助手 协议执行核验

## 目标

只读核验团队交付评论是否显式 @项目调度助手，并把缺失情况记录给项目主管；不修改代码。

## 固定规则

完成定义必须同时包含：

1. 交付评论；
2. 精确远端 branch/SHA 或明确 blocked 证据；
3. 测试/环境/审核结果；
4. 显式 mention：`[@项目调度助手](mention://agent/826abb3f-34c0-4d9a-afff-2a0b1a002221)`。

仅有普通评论、仅有 agent 自报、仅有 issue status 都不能触发下一阶段。

## 工作内容

对最近本轮相关卡 DAV-153、DAV-154、DAV-155、DAV-156、DAV-157、DAV-151、DAV-126 检查最新完成/阻塞评论：

- 是否有精确 SHA/结果；
- 是否有显式项目调度助手 mention；
- 缺失时在对应 issue 留一条简短补齐评论并 @项目调度助手；
- 不重复启动代码任务，不修改仓库，不改配置；
- 若评论系统不触发后续 run，记录为编排平台限制，不伪造触发成功。

## 交付

在 issue 评论中给出：检查卡片、缺失 mention 的卡片、已补齐的评论 ID、是否观察到新 run。完成后必须显式 @项目调度助手。
