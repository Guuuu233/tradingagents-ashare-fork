## 架构方向（已裁定）
修 registry/extractor/gate 的语义边界，不降低 Stage-4 clean 门。

### 1. 引入明确的 numeric/price semantic role
不要再把所有 `X 元`/关键词邻近数字都等价视为 A 股交易坐标。至少要区分：
- A-share coordinate quote / executable coordinate：需要合法 basis + as_of；
- typed disclosure price（大宗交易/龙虎榜/定增/增减持/回购等）：raw/pit_raw，若进入 qfq 坐标推理必须显式转换；
- derived valuation estimate：可作为推理信息，但不是 vendor_qfq 市场坐标；不得直接作为 executable level，除非有合法转换/锚定契约；
- foreign quote / foreign currency：不得参与 A 股 raw/qfq coordinate mix；
- non-coordinate numeric：日期、百分比、亿元金额、市值、股本、倍数、EPS/财务每股指标等，不应生成 A 股 price_ref。

实现可新增 `semantic_kind/price_role` 或等价结构；不要用简单黑名单堆补丁替代类型语义。

### 2. executable 关键词必须单一来源
消除 `_LEVEL_PATTERN` 与 registry `_PRICE_KEYWORD_PATTERN` 的重复词表。建立共享的 executable-price keyword/解析 helper，registry 与 gate 共用。
必须覆盖并测试：目标价/目标位/止盈/止损/入场/进场/买入/卖出/建仓/开仓/出场/加仓/减仓。
任何 gate 能识别为 executable 的值，registry 必须有机会登记 ref；反之不允许因百分比/数量/年份误抽成 executable。

### 3. typed disclosure 检测收敛
`大宗` 不得在“大宗商品/原油及大宗涨价”等语境误判 `block_trade`；至少要求 `大宗交易` 或等价明确证券交易语义。

### 4. cross-basis 规则从“同报告共存”收敛到真实坐标混用
保留并强化：
- same-sentence mixed concrete basis；
- raw/pit_raw 直接进入支撑/阻力/锚/目标/止损等 qfq coordinate reasoning；
- known b188 类 anchor 必须继续 blocked。

不得仅因为同一长报告不同段落分别出现 typed disclosure raw 与技术 qfq 就 report-wide 全部互相笛卡尔配对判污染。若保留 report-level 规则，必须证明存在明确语义连接，而非只靠“同一报告”。

### 5. Stage-4 与 pool bridge 边界
- **禁止**把 Stage-4 clean 改成“只看 executable violations”来绕过当前问题；
- pool→registry bridge 不是本卡主路线。若实现，只允许严格 source-backed identity/provenance，不得按数值相等直接继承 basis；必须单独测试数值巧合不误归因。

## 必须 RED→GREEN 的锚点
### false-positive 必须消失
- 美股/外币报价如 `579.27 美元` 不得成为 A-share decision-driving qfq ref；
- 日期 `2026-08-14` 不得抽成 2026.0 price；
- `900亿元市值` / 股本 / 百分比 / 倍数不得成为 price_ref；
- EPS/每股财务指标不得自动当股票坐标；
- PB/PE 推导的 `27.14 元估值底线` 等必须标记 derived estimate，不得伪装 vendor_qfq；
- “原油及大宗涨价”不得触发 block_trade raw；
- 百分比回撤 `-4.90%`、数量 `2.0亿股` 不得抽成 executable level。

### true-positive 必须继续拦
- raw/pit_raw disclosure price 与 qfq 支撑/目标在同一坐标推理中直接混用；
- 无 factor provenance 的 raw→qfq conversion；
- 模型自拟、source-unbacked 的真实 executable target/stop/entry；
- audit error 继续 fail-close；
- b188060f 类已确认污染锚点保持 blocked。

### executable 注册一致性
`建议入场区间：35.20 元`、`建仓价`、`减仓价`、`目标位` 等：gate 若识别为 level，registry 必须同步抽取；有合法 qfq provenance 时可 pass，无 provenance 时应是 wrong/unbacked 的真实 blocker，而不是词表分叉造成的假 blocker。
