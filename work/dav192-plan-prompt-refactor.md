# DAV-192: 深度联想Prompt重构

## 任务目标
不新增数据源，仅通过Prompt优化+流程调整，提升30%联想深度，解决当前7个分析师和8个决策层Agent"深度联想不足"问题。

## 当前问题（基于京东方A分析报告诊断）
1. **辩论深度不足**：多空辩论仅1轮，无法深度穿透
2. **产业链联想缺失**：分析师提到"面板行业"但不联想上游玻璃基板/驱动IC价格、下游手机出货量、国际对标三星显示
3. **传导路径浅**：只说"消费以旧换新→终端需求"，不推演"居民收入→消费意愿→换机周期"
4. **分析师孤岛**：7个分析师并行独立，基本面分析师看不到宏观分析师的"原油上涨10%"
5. **证据链薄弱**：投研经理没有明确的"证据充分/薄弱/缺失"审查

### 子任务2：宏观分析师Prompt增强（4h）
**文件**：`tradingagents/prompts/zh.py` 中的 `macro_system_message`

**核心修改**：在"What Next"部分插入【强制联想清单】，针对5大行业类型（消费电子、新能源车、半导体、石油化工、金融地产）给出具体操作指令：
- 上游成本传导：XX价格 → 成本 → 毛利率（量化弹性系数）
- 下游需求传导：终端出货量 → 订单 → 营收规模
- 政策催化传导：政策力度 → 终端销量 → 面板/电池订单
- 国际对标映射：三星/LG/特斯拉股价 → 行业景气度验证

**强制要求**：
- 每条传导链路必须有方向（正/负相关）和量级（强/中/弱）
- 必须给出时滞（政策→基本面2-6个月，原材料→成本1-3个月）
- 缺乏数据时写"【数据缺失】XX指标无法获取"，不得臆测

### 子任务3：基本面分析师Prompt增强（4h）
**文件**：`tradingagents/prompts/zh.py` 中的 `fundamentals_system_message`

**新增框架**："产业链环境与关键指标联动"
- 上游议价权：原材料占成本比重、成本传导弹性、供应商集中度、应付账款周转天数
- 下游需求：主要客户行业景气度（从宏观/新闻报告提取）、在手订单/合同负债、应收账款周转天数、客户集中度
- 行业供需格局：产能利用率、竞争对手资本开支、ASP环比趋势、库存周转天数
- 国际对标：同行业国际龙头PE/PB、近1年股价走势、订单/产能数据

**强制要求**：
- 每项分析必须给出具体数据+同比/环比/行业均值对比
- 必须从宏观/新闻分析师报告提取原材料价格、下游需求预测
- 必须给出"成本上涨X% → 毛利率影响Y%"的敏感性分析

### 子任务4：新闻分析师Prompt增强（3h）
**文件**：`tradingagents/prompts/zh.py` 中的 `news_system_message`

**核心修改**：强制要求"三层传导分析"
- 第一层：事件本身（What）- 标题+时间+信息源可信度+核心事实
- 第二层：直接影响（Why + So What）- 对基本面/市场情绪的直接影响
- 第三层：间接传导（What Next）- 上游/下游/同行/国际联动

**反面案例**：❌ "工信部发布AI手机白皮书，利好消费电子板块"
**正面案例**：✅ "AI手机渗透率目标30% → 国内手机出货2.8亿部×30%=8400万部AI手机（+100% vs当前15%）→ AI手机需高刷OLED+更大电池 → 单机显示模组ASP提升15-20% → 京东方OLED稼动率从75%提升至85%（假设占国产OLED份额40%）"

### 子任务5：多空辩论Prompt强化（3h）
**文件**：`tradingagents/prompts/zh.py` 中的 `bull_prompt` 和 `bear_prompt`

**三轮递进框架**：
- 第1轮（开场立论）：提出1-2个核心claim，必须基于硬数据+证据来源+置信度（0.00-1.00）
- 第2轮（攻防回应）：必须正面回应对方上一轮claim（responded_claim_ids不得为空），用更强数据反驳或指出逻辑断裂
- 第3轮（收官深化）：聚焦最核心分歧点，使用"极端情景推演"，量化风险收益比

**强制要求**：
- 每个claim必须注明来源："根据XX分析师报告，YY数据显示ZZ"
- 禁止重复分析师已陈述的内容，必须在其基础上进一步推理
- 当多个分析师结论矛盾时，必须明确说明如何权衡

### 子任务6：投研经理Prompt强化（3h）
**文件**：`tradingagents/prompts/zh.py` 中的 `research_manager_prompt`

**深度裁决框架**（基于3轮辩论）：
- 第一步：证据链完整性审查 - 标注"证据充分/薄弱/缺失"
- 第二步：传导路径验证 - 检查时滞/量化/历史验证是否合理
- 第三步：焦点分歧裁决 - 逐个裁决哪方证据更强、逻辑更严密
- 第四步：极端情景测试 - 推演多空双方的极端情景是否合理
- 第五步：风险收益比量化 - 综合给出上涨空间/下跌风险/赔率

**输出纪律**：
- 总字数800-1200字（比单个分析师更长）
- 必须有明确的"多头胜/空头胜/势均力敌"结论
- 必须给出"建议仓位"（0-100%）和"止损位"（具体价格/跌幅）

## 验证标准

### 验证1：辩论深度（定性）

- [ ] 多空辩论轮次≥3轮
- [ ] 每轮claim都有具体数据支撑
- [ ] 第2-3轮有正面回应对方claim
- [ ] 投研经理有明确的证据链审查+焦点裁决

### 验证2：联想深度（定性）
检查宏观+基本面分析师报告：
- [ ] 有明确的"上游成本传导"分析（原材料→成本→毛利率）
- [ ] 有明确的"下游需求传导"分析（终端需求→订单→营收）
- [ ] 有明确的"时滞"说明
- [ ] 数据缺失时有"【数据缺失】"标注

### 验证3：报告质量对比（定量）
用相同个股在DAV-191和DAV-192各生成1份报告，对比：
- 宏观分析师报告字数：2820 → 3500-4000字符
- 基本面"产业链"段落：~200 → 800-1000字符
- 多空辩论总轮次：2轮 → 6轮
- 投研经理报告字数：~600 → 1000-1200字符
- "传导/联想"关键词：5-8次 → 15-20次
