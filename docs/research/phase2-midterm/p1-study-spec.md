## 1 样本区间与交易日历

- **信号日区间**：`2019-06-03` 至 `2025-12-31`（约 6.5 年）。
  - 上限取 2025-12-31：T+40 窗口约需 40 个交易日 + 最多 5 个展期日，2025-12-31 的信号最迟约 2026-03 中旬成熟，截至跑数日（2026-10）已全部成熟；窗口未走完的信号日按 `pending_due` 类型化排除，不入任何统计。
  - 下限取 2019-06：覆盖 2020 年初急跌、2021 结构行情、2022–2024 不同波动 regime；更早数据的 ST/停牌/行业归属证据链更薄，若实测发现更早段缺失率显著更高，报告中按年段分列，不混算。
  - 敏感性：另报 `2016-01-01` 起的长样本（若数据源覆盖）作为稳健性对照，主口径仍以 2019-06 起为准。
- **交易日历**：上交所/深交所交易日，来源 Tushare `trade_cal`（exchange=SSE，is_open=1），与 `trade_calendar.py` 的日历口径核对一致后落缓存。日历索引一律用真实交易日序列索引，禁止自然日加法或 DataFrame 行切片（沿用 `resolve_horizon_calendar_window` 的不变量）。
- **每项结果同时报**：信号日区间、有效信号日数、股票数、股票-日观测数、各类型缺失/排除计数。

## 2 股票池（PIT，含退市股）

母池为**全 A 普通股**，含已退市股票；逐项过滤条件均按信号日 T 的当时口径判定：

| 规则 | 判定 | 数据源（当时口径） |
|---|---|---|
| 交易所 | 剔除北交所（`.BJ`、8xx/4xx/920 前缀） | `canonicalize_symbol`（与 V-03a 相同函数） |
| ST/*ST | 剔除 T 日为 ST/*ST 者 | Tushare `daily` 行的名称字段不可信（当时名称需另证）；**主证据**：Tushare `namechange`（ST 标记变动区间）+ `daily_basic`/行情停牌佐证；若 `namechange` 对历史区间覆盖不全，降级为按名称含 "ST" 的当时快照法并在缺失台账中报计数 |
| 上市天数 | 剔除上市不满 60 个交易日者 | `stock_basic.list_date` + 交易日历计数（与 V-03a `is_listed_for_n_days` 同口径） |
| 不可交易 | 剔除 T 日停牌 / 无法执行入场者 | T+1 开盘入场可执行性判定（停牌、成交量 0、一字涨停 → `unexecutable_entry`，定义见 §4） |

- **退市股**：`stock_basic` 返回 list_status ∈ {L 上市, D 退市, P 暂停} 全量；退市股保留在母池中，其 T+40 窗口跨越退市整理期的按价格数据可得性类型化处理（`data_missing`/`suspension`），报分母与排除计数，**不静默删除**。
- **沪深300 + 中证500 子集**：当时成分由 Tushare `index_weight`（000300.SH / 000905.SH，按月公布的权重记录，取 T 日前最近一期且生效的权重>0 名单）确定；`index_weight` 按月发布存在发布滞后，PIT 处理为「T 日可见的最新一期成分」，滞后方向与残留偏差在报告中说明。若 `index_weight` 权限或覆盖不足，逐条报告，不用当前成分静默补齐。
- 全部过滤计数逐日逐类报台账（仓外明细，报告只放汇总）。

## 3 行业归属与基准腿

- **行业归属**：一律调用 `tradingagents/dataflows/sw_industry.py` 的 `resolve_sw_l1_benchmark(symbol, T)`（DAV-1453 口径 A，`in_date <= T < out_date`，Y/N 两批都查）。不手写 `index_member_all`、不用 `con_code`、不用 akshare 当前成分。
- **性能处理**：`resolve_sw_l1_benchmark` 每调用一次发起 3 个 API 请求（index_classify + 两批 index_member_all）。研究脚本按 symbol 缓存结果（仓外 parquet），同一 symbol 全样本期只查一次其成分区间表，再对全部信号日本地过滤；`index_classify` 全局只取一次。逐条缺失记录 `reason`，不重试静默补齐。
- **行业基准收益**：Tushare `sw_daily`（申万一级指数日线）。`R_SW(T→T+40)` 用与个股完全相同的窗口端点：T+1 开盘入场对应指数端点为 T+1 开盘价，T+40 收盘退出对应 T+40 收盘价；指数开盘不可用时降级为前收（记录口径标记），停牌日指数仍出数（指数不停牌）。申万指数代码与 L1 `l1_code` 的映射取自 `index_classify` 的 `index_code`。

## 4 标签口径（预测口径）

- **定义**（与计划 P2 裁定一致，`return_labels.py` 为唯一结算真相源；P2 未合入前在研究脚本内按同一定义实现并在代码注释注明）：
  - 入场：T+1（`trading_days[signal_idx+1]`）开盘价；
  - 退出：T+40（`trading_days[signal_idx+40]`，信号日起第 40 个交易日）收盘价；
  - `r_stock = P_exit_close / P_entry_open − 1`；`y_rel = 1[r_stock − r_SW > 0]`；`r_rel = r_stock − r_SW`（连续型行业相对收益，相关系数与 IC 用连续值，基率用 0/1）。
- **价格基准**：主口径 `raw` 不复权价格 + 现金分红/拆股按 `total_return` 另算（与契约 §4d 对齐）；
  - **简化决定（请总控确认）**：本研究主口径用 **vendor_qfq 前复权价格的纯价格收益**（`price_basis=vendor_qfq, return_type=price_return`），理由：(a) 行业相对收益中分红腿大部分被同行业共同分红节奏抵消；(b) `sw_daily` 指数点位本身不含成分股分红，全收益口径反而引入基准腿不对称；(c) 40 交易日窗口分红影响量级小。敏感性：对含分红事件的子样本，报 qfq 口径与 raw+total_return 口径的差分分布。
  - 复权因子来源：Tushare `adj_factor`；`vendor_qfq` 口径为 `price × adj_factor(T_exit) / adj_factor(T_entry)` 的等价实现，具体换算与 D-069 附注的「前复权口径」一致并在代码中注明。
- **类型化缺失**（沿用 `OutcomeStatus` 7 态语义，不新增状态）：`pending_due`（窗口未走完）、`suspension`（目标日停牌且展期用尽）、`unexecutable_entry`（T+1 停牌/无量/一字涨停）、`data_missing`（bar 缺行）、`provider_failure`（取数失败）。预测口径下 `suspension` 与 `unexecutable_entry` 不计入 r_rel 分母但计入台账；**研究不采用执行口径的顺延收益**（评估师意见：固定窗口预测标签不得拿执行结算返回值代替）。
- **同日重叠**：同一信号日内不同股票窗口天然重叠；估计方法见 §5。

## 5 交付物对应的方法

### 5.1 同日相关结构（交付物 1）

- **随机变量**：`r_rel_i(T)`（股票 i、信号日 T 的连续型行业相对收益）。
- **配对单元**：同一信号日 T、同组 g ∈ {全体, 同周（同一 ISO 周的信号日合并估计，非配对条件的放宽，而是把同周多个信号日的同组对合并进入同一估计）, 同行业（两只股票 T 日一级行业相同）, 同风格桶（两只股票同落 §5.3 风格桶）} 内的**无序股票对 (i,j)，i≠j**。
- **估计量**：`ρ_g = mean over pairs of z(r_i)·z(r_j)` 的配对形式——先对每个信号日把 `r_rel` 做横截面 z 标准化，组内两两乘积取均值（等价于该日组内成对相关）；再跨信号日取**等权平均**与**精度加权（按对数）平均**两口径。报告估计窗口（全部信号日）、对数、股票-日数。
- 备选：同日两两 Pearson（每日一个相关系数再跨日平均），作为稳健性并列。不估计逐股对的时间序列相关（每对观测数太少）。

### 5.2 日级横截面统计量的自相关结构（交付物 2）

- **排序分数来源**（零模型，报告中显式标注"这不是系统能力"）：
  1. 公开因子分数：动量（T−1 起 120 交易日累计收益，跳过最近 20 日）、估值（`daily_basic` PE_TTM/PB 取负作分）、低波动（120 日收益波动率取负）、规模（`total_mv` 取负/取正两向）——各单因子与等权合成 `score_composite`；
  2. 模拟信号：横截面标准正态分数 + 假设真 IC ∈ {0.00, 0.02, 0.05, 0.08, 0.12}（噪声叠加法生成，`r_rel = ρ·z(score) + sqrt(1−ρ²)·ε` 的反解），种子固定（见 §7），情景标注为情景。
- **统计量**：每个信号日 T 计算 Spearman 排序 IC `IC_T = corr_s(score_i(T), r_rel_i(T))` 与高低分组差 `D_T = mean(r_rel|top quintile) − mean(r_rel|bottom quintile)`；同时算 `y_rel` 版本作对照。
- **自相关报告**：对 `IC_T` 与 `D_T` 序列报 lag 1–120 的 ACF/PACF、Ljung–Box 于若干 lag、长程方差估计；**保留原交易日索引**（insufficient 日期记缺失、不把相邻观测当相邻交易日）。
- **HAC/移动块候选**：Newey–West 带宽 ∈ {40, 60, 80, 120, 自动 BW（Andrews）} 与移动块自助块长 ∈ {40, 60, 80, 120}，按实测 ACF 衰减与覆盖率（对已知方差的模拟序列做覆盖校验）推荐，不在实测前定死。

### 5.3 风格暴露解释力（交付物 3）

- **风格因子**（全部仅用 T 日及之前可知数据）：规模 `ln(total_mv)`、估值 `1/PE_TTM` 与 `1/PB`（负值与缺失类型化处理）、动量 `R(T−140,T−20)`、波动 `σ_120d`。
- **分桶**：每个信号日对各因子做横截面十分位；`同风格桶` = 四因子十分位向量完全相同（会稀疏，另报"规模×估值"25 桶粗分版）。
- **解释力**：
  a. 每日横截面回归 `r_rel_i(T) ~ 1 + z(风格)_i(T)` 的均值 R²（Fama–MacBeth 风格，只作描述）；
  b. 风格中性化后的 §5.2 自相关与 §5.1 相关重算（残差 `r_rel` = 原值 − 同日风格拟合），并列报告；
  c. 跨时段样本外：前 2/3 时段估系数、后 1/3 时段预测 R²（防过拟合证据）。

### 5.4 分行业基率（交付物 4）

- `p_base_rel_t40` 的历史依据：分行业滚动/扩窗 `y_rel` 均值，**只用截至 T 已成熟的标签**（信号日 ≤ T 且退出日 ≤ T 的样本；实际实现为「退出日 ≤ T」即成熟，退出日=T+40 后于信号日 40 交易日）。
- 收缩：行业基率向全市场扩窗均值做 Beta–Binomial 收缩，`p̂_j(T) = (n_j(T)·p̄_j(T) + m·p̄_mkt(T)) / (n_j(T) + m)`，m ∈ {50, 200, 500} 敏感性；行业历史样本不足 m 时结果偏向市场均值，**不填 50%**。
- 报告：每行业每年度基率、跨时波动（滚动窗口方差）、样本量；标注供 `p_base_rel_t40` 使用。

### 5.5 信息量—成本前沿（交付物 5）

- **抽样方案**（与 M2 对齐）：每个信号日按当时沪深300+中证500 子集做**行业分层随机抽 N 只**（行业配额 ∝ 当日行业成员数，最少 1 只/行业，剩余名额轮转补齐），N ∈ {10, 20, 30, 40}；另报全市场随机抽 N 作对照。种子固定。
- **有效信息量**：对每日抽样横截面的 IC_T 与 D_T 日序列，用 §5.2 实测相关结构折算年新增有效信息量：`n_eff = n_days × (1 + 2·Σ_{k≥1} ρ_k)^{-1}` 形式的长程方差修正，并对重叠窗口用 §5.1 实测股间相关修正"份数≠独立量"；给出公式与假设，**不直接用「股票数×交易日数÷40」**。
- **排序精度**：抽样子集 IC 相对全集 IC 的标准误、Top-N 重合度，随 N 的曲线。
- **行业覆盖**：N 只样本覆盖的一级行业数分布（每日均值、分位数）。
- **成本账本**（参数化模型，不编造人民币金额）：
  - token：以 gemini 双档约 130 万 token/份（PROJECT_STATE 09-27，含缓存命中约 19%）为参考档，另参数化单档用量 `t_单档 ∈ {0.35, 0.5, 0.65}×130 万` 三情景（注明双档历史参考不能直接当中线单档用量）；
  - 费用：`C = N × (t_in×p_in + t_out×p_out + t_cached×p_cached)` 参数化表达，列出需总控/运营补的真实单价字段（输入/输出/缓存三价），不给人民币数值；
  - 延迟：按实测的"一份双档约 25 分钟、并发上限 4"（PROJECT_STATE swe-2 试跑）参数化 `latency ≈ N × t_per / concurrency`，标注该数字来自 swe-2 通道、gemini 通道待实测；
  - 产出：N × {年新增有效信息量, token, 参数化费用, 延迟, 行业覆盖, 排序精度} 表格 + 边际信息/边际成本曲线。

### 5.6 两项冻结口径（交付物 6）

- `primary_cross_sectional_metric`：推荐**日级 Spearman 排序 IC 为主、高低分组差为辅**；同时检验并列值（同分并列占比）、常量分数日期、分组大小（N 小时 quintile 不稳 → 改 tercile 的敏感性）后给最终建议。
- `min_daily_cross_section_n`：**本卡不推荐单一数值**；对 N ∈ {10, 20, 30, 40} 完整报告：有效日期覆盖率（候选阈值下剩余有效信号日占比）、行业覆盖、IC_T 与 D_T 的方差与自相关稳定性，由总控据此在 M2 结果暴露前冻结。
