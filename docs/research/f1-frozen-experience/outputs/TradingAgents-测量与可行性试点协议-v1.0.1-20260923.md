## 0 摘要

**目的**：在建设任何经验系统之前，用最低成本回答四个问题：

1. 数据能否做到时点可信（PIT）；
2. 经验包是否稳定、可复现地改变 TA 的概率输出；
3. TA 自身的运行噪声与成本有多大；
4. 在真实日历、数据结构与预算下，正式确认实验能否完成。

**不回答**：经验包是否提高准确率、校准或收益。这些需要带标签数据，属于阶段 L 及之后。首轮不做在线更新。

**阶段**：H（PIT-light 历史审计）与 P（最小可信经验包）并行 → R（重复运行测量）与 E（Expectation-PIT 审计与历史 S/U）并行 → L（带标签开发试点）→ D（确认实验决策与预注册）。

**硬终止条件只有五类**：

- 数据资格无法证明；
- 格式或语义失效；
- 集成审计确认经验包未被消费；
- 成本超预算；
- 可行性计算表明，在预算与版本周期内达不到所需信息量。

**无标签阶段不以效果大小终止**（§5.7 的精度启用条件除外）。

**确认实验已锁定的规则**：

- 估计目标为事件等权；
- 按交易日历聚合做推断；
- 跨季检验逐季做 $t(G-1)$；
- 固定顺序检验 H1→H2→H3；
- 事前冻结唯一的 $C^*$；
- 成本以向量形式报告。

## 1 研究对象与记号

**研究问题**：在有合格事前卖方参考预期、首次年度业绩预告可核验的事件子总体中，冻结经验包能否改善指定 TA 节点对既定 T+10 行业相对结果的原始概率？

| 记号 | 含义 |
|---|---|
| $i$ | 合格机会（首次年度业绩预告事件） |
| $Y_i\in\{0,1\}$ | 按冻结契约计算的 T+10 行业相对结果 |
| $q_i=P(Y_i=1\mid \text{截止时合法信息})$ | 潜在条件概率，**不可直接观测** |
| A | 冻结的 TradingAgents，单次运行 |
| B | A + 冻结经验包，注入事前固定的单一节点 |
| S | 冻结统计程序给出的条件基率（高于 / 覆盖 / 低于，并做收缩） |
| U | 开发期冻结的无条件基率（原评议记为 $p_0$） |
| M | $p^M=(1-w)p^A+wp^S$，$w$ 由开发数据按时间顺序交叉验证选定并冻结 |
| $A_K$ | A 在同一冻结输入下独立运行 $K$ 次后取平均 |
| $C^*$ | 事前冻结的最佳简单基准（§7.5） |
| $d_i$ | $(p_i^B-Y_i)^2-(p_i^C-Y_i)^2$，C 为对照臂（A、$C^*$ 等）；**负数表示 B 更好**；$\Delta=E[d]$ |
| $\delta_{\min}$ | 预注册的最小有用改善，$>0$ |

**符号约定**：检验与区间一律使用 $\Delta$，负数表示改善。讨论上界时的"改善量"记为 $I=-\Delta$。两种符号不得混用。

## 2 阶段与闸门

| 阶段 | 内容 | LLM | 标签 | 主要产出 | 硬终止 / 转向 |
|---|---|---|---|---|---|
| H | PIT-light 历史审计 | 否 | 历史 | 每季事件数 $m_g$、季数 $G$、日期集中度、季内结果相关 $\rho_Y$、逐季基率 $U_g$ | 无法构建当时的行业归属与股票池 |

| D | 确认实验决策与预注册 | 否 | — | 有效样本、所需季数、预算、预注册文本 | 可行性不足时，降级为估计性研究或重设问题 |

## 3 阶段 H：PIT-light 历史审计

本阶段不需要卖方预期的 PIT，但其余数据必须是事件当时的状态：

- 首次预告的版本与公告时间戳；
- 复权价格；
- 事件日当时的行业归属与行业基准。行业分类会调整，不得用现行分类回填；
- 当时的可投资股票池，包括此后退市或长期停牌的股票；
- T+10 按冻结的标签契约计算。

| 产出 | 用途 |
|---|---|
| 每季合格事件数 $m_g$、季数 $G$、前 $k$ 个交易日的事件占比 | 确定所需季数与日历跨度（§7.3） |
| 季内结果相关 $\rho_Y$：同季全体；另报同周、T+10 窗口重叠的子集 | 设计效应规划（§8.4） |
| 逐季基率 $U_g$ 及其跨季波动 | 判断 U 的稳定性、季级共同冲击的量级 |

**边界**：

- 历史 0/1 结果只能估计 $\rho_Y$ 与 $U_g$，不能直接得到 $\mathrm{Var}(q)$（§8.1）。
- 本阶段不涉及 LLM，因此没有参数记忆泄漏问题；本阶段结果也不用于判断经验包效果。

## 4 阶段 P：最小可信经验包与集成审计

### 4.1 经验包字段

| 字段 | 含义 |
|---|---|
| opportunity_id、contract_version | 机会编号与标签契约版本 |
| event_version、event_at、cutoff_at | 首次预告版本，以及两道时间截止（参考预期截止、决策输入截止） |
| forecast_range、consensus_definition | 预告区间与利润口径 |
| consensus_median、coverage、age、dispersion | 参考预期及其可信度描述 |
| surprise_class | 高于 / 覆盖 / 低于；不可比的单列 |
| base_rate、support_n、support_dates | 收缩后概率、原始事件数、时间支持范围 |
| base_rate_rule、fallback_level | 估计与回退来源 |
| thesis_id、version、provenance | 命题及其来源 |
| applicability、counterevidence、invalidation | 适用条件、反例、失效条件 |
| evidence_ids、content_hash | 可追溯的原始证据 |

### 4.2 生成规则

- 基率由冻结的统计程序生成：$\hat p_g=(k_g+\kappa U)/(n_g+\kappa)$。$\kappa$ 只用更早且已结算的数据选定。LLM 不自行计算基率，也不挑选条件。
- 提示词中明确声明：基率不是结论，命题不是已证实的机制，模型可以有证据地偏离。
- 两臂都保留完整合法的底座。B 多出的上下文长度、延迟和费用，如实计入干预成本。
- 合成材料只用于接口调试与敏感性调试，不作为淘汰真实干预的依据。

### 4.3 概率输出规格（本阶段冻结）

- **语义**：$P(\text{T+10 行业相对收益}>0\mid\text{截止时合法信息})$，与标签契约同义。
- **刻度**：至少精确到整数百分点。粗刻度（如只允许 45/50/55）会隐藏小于半格的稳定改变，使 B 与 A 输出相同成为常态。
- 解析规则、无效输出的定义和重试政策全部写死。

### 4.4 注入节点

- 事前固定单一决策节点。
- 共享上游仅限确实不受处理影响的部分；受影响的下游全部重跑。
- 结论表述为"该节点使用经验包带来的增量"。

### 4.5 集成审计

当 B 与 A 输出大量相同，或反应异常时，首先执行以下检查：

1. 经验包是否到达预定 Agent（查调用日志、上下文哈希）；
2. Agent 是否引用了包内关键字段，引用的数字是否一致；
3. 输出刻度是否允许所需的精细度；
4. 案例本身是否与经验包内容相关。

只有确认"信息未被消费"，才判定工程实现失败。即便如此，这也不等于"经验无用"。

## 5 阶段 R：重复运行测量

### 5.1 目的

在同一次实验中同时测得五项内容：

- A、B 各自的运行噪声；
- A→B 的稳定改变量；
- 改变方向的一致性；
- 可复现度；
- 成本。

**不得先单跑一次 A/B、事后再测噪声**，否则会把运行噪声误当成干预效果。

### 5.2 样本

- 约 20 个阶段 P 的可信机会，按事前规则抽取。
- 每臂重复 $R=2$ 次，共约 80 次被测分支运行。若重跑完整链路，每次运行都包含多次模型调用。
- 这是预算建议，不是统计充分性门槛（§5.6）。

### 5.3 输入冻结

每个机会的全部外生输入（行情、研报、基率查询结果、经验包）以快照加内容哈希固定。同一机会的四次运行，输入完全相同。

### 5.4 运行安排与记录

**安排**：

- **重复内配对**：同一重复中的 A、B 紧邻运行，顺序随机，会话独立。
- **重复间分块**：第 1 次和第 2 次重复放在两个事先登记的不同时间块。
- 禁用响应级缓存复用。
- 使用预先指定的登录账户运行。未登录而回落到默认本地账户的输出，不计入样本。

**逐次记录**：精确模型标识、供应商指纹（若提供）、系统提示与经验包的哈希、采样参数、调用时间、会话 ID、缓存状态、重试、token、延迟、费用、原始输出、解析后的概率。

**这样安排的理由**：

- 共同的时间效应，会在同一重复的 $B-A$ 中抵消。
- 某个时间窗口特有的 A/B 交互 $\tau$，在两次重复之间相互独立，会进入噪声。
- 反之，若两次重复处于同一窗口，$E[D_{i1}D_{i2}]=u_i^2+\mathrm{Var}(\tau)$，稳定改变量会被高估。

**版本漂移**：模型名称不变，不保证底层服务不变；上述记录用于事后识别漂移。若供应商无法提供足够的稳定性，这是整个前瞻实验的额外随机来源，须在阶段 D 计入。

### 5.5 估计量

记 $D_{ir}=B_{ir}-A_{ir}$，$u_i=E[p^B\mid i]-E[p^A\mid i]$。

| 目标 | 估计量 | 说明 |
|---|---|---|
| $u_i^2$（稳定改变量的平方） | $X_i=D_{i1}D_{i2}$ | 只要求两次重复的生成随机性条件独立；不要求两臂噪声相等，也不要求各机会噪声相等 |
| $\sigma_A^2$ | $\overline{(A_{i1}-A_{i2})^2}/2$ | 20 个机会时，$\sigma$ 的相对误差约 16% |
| $\sigma_B^2$ | $\overline{(B_{i1}-B_{i2})^2}/2$ | 同上 |
| 平均改变量 $\bar u$ | $\overline{(D_{i1}+D_{i2})/2}$ | |
| 方向一致性 $c=\bar u^2/\overline{u^2}$ | $(\overline{D_{\cdot1}}\cdot\overline{D_{\cdot2}})\,/\,\overline{X}$ | 比值估计，报告按机会重抽样的区间；用于 §8.4 |
| 可复现度 | $\mathrm{corr}_i(D_{i1},D_{i2})$ | |
| $A_K$ 可白拿的改善 | $\hat\sigma_A^2(1-1/K)$ | 作为 $A_K$ 进入 $C^*$ 候选的依据 |
| 成本 | 每臂的 (\$, tokens, 延迟 P50/P95) | |

**使用要求**：

- **独立性无法由检查证明。** 独立会话、禁用缓存、冻结输入、随机调度与分块调度，只能降低违背风险。可以发现的明显违例有两种：完全相同输出的比例异常；$D_{i1}$ 与 $D_{i2}$ 随时间块系统性变化。
- 估计值为负时，如实报告为"未辨认出超出噪声的稳定差异"，不得隐藏。
- **不使用** $\mathrm{Var}(B_1-A_1)-\mathrm{Var}(A_1-A_2)$。它隐含假设 $\sigma_A=\sigma_B$，而经验包改变了上下文，两臂噪声相等恰恰存疑。

### 5.6 本阶段能与不能下的结论

- **能下的结论**：噪声量级、成本、格式有效率、改变方向的结构，以及能否排除"大幅稳定改变"。
- **不能下的结论**：改善是否存在、是否达到 $\delta_{\min}$、是否校准、是否赚钱。
- **情景参考**：设稳定改变的 RMS 为 3.2pp，两臂噪声分别为 3pp 和 5pp。此时交叉乘积估计 ≤0 的概率约 15%；可复现度为 0.21 时，检验功效约 23%；20 个机会要达到 80% 功效，需要可复现度 ≥0.54。换言之，20 个机会只够区分"几乎不动"与"大幅、稳定地动"。

### 5.7 终止与启用规则

**硬终止**（修改设计后重试，或停止）：

1. 格式或语义无效率超过预设上限；
2. 成本或延迟超出预算；
3. 集成审计确认经验包未被消费。

**效果类终止默认不启用。** 启用须同时满足以下三点：

- **门槛**：由 $C_i\le 2\lvert u_i\rvert\max(a_i,1-a_i)$ 可得，系统改善 $\le 2M\cdot\mathrm{RMS}(u)$，其中 $M=\max_i\max(\bar A_i,1-\bar A_i)$（保守可取 $M=1$）。据此取门槛 $\theta=\big(\delta_{\min}-\max(0,\hat\sigma_A^2-\hat\sigma_B^2)\big)/(2M)$。扣除项的含义是：单次运行比较中，B 若噪声更小，可额外获得 $\sigma_A^2-\sigma_B^2$ 的改善。
- **精度**：只有当零效应下置信上界的中位数低于 $\theta^2$ 时，才可启用。两臂噪声相等时，近似条件为

  $$\sigma\le\sigma^*\approx\theta\left[\frac{\sqrt n\,\sqrt{R(R-1)/2}}{2\,t_{0.95,\,n-1}}\right]^{1/2}$$

  模拟核对显示该式略保守，实际临界值高 3–8%。
- **判据**：启用后，以 $\overline{X}$ 的单侧 95% 置信上界 $<\theta^2$ 作为终止依据，**不得用点估计**。原因：在噪声 ≥1pp、零效应时，点估计规则的判死率约 50–56%，接近抛硬币；对真实 3.2pp 的稳定改变，点估计规则的误杀率为 15.6%，上界规则仅 0.5%。

临界噪声 $\sigma^*$ 参考：

| $\theta$ | 20 机会 × 每臂 2 次 | 50 × 4 | 200 × 10 |
|---|---|---|---|
| 0.25pp | 0.28pp | 0.57pp | 1.34pp |
| 0.50pp | 0.57pp | 1.14pp | 2.68pp |

按本协议规划的规模（20 个机会 × 每臂 2 次），每次运行噪声超过约 0.3pp（θ=0.25pp）或约 0.6pp（θ=0.5pp）时，该规则不会被启用；扩大试点可以提高临界值（见上表）。因此阶段 R 应定位为测量。

## 6 阶段 E、L、D 要点

### 阶段 E：Expectation-PIT 审计

- 按事前的日期规则与股票范围规则，抽取约 50 个发现事件，不得只挑容易成功的案例。
- 逐层记录资格损失：首版预告、事前参考预期、利润口径、行业映射、标签结算。
- 审计通过后，按年滚动估计历史 S 相对 U 的样本外 Brier 改善。S 只用更早且已结算的数据构建。
- 这一结果只提供 $\mathrm{Var}(q)$ 的下界证据，以及 S 效应的跨季波动，不提供上界（§8.1）。

### 阶段 L：带标签开发试点

- 与确认集独立；优先采用前瞻样本，因为历史 LLM 输出存在参数记忆污染。
- 估计：$E[d]$、$\mathrm{Var}(d)$、时间依赖、覆盖率。
- 冻结：$w$、$\kappa$、$K$、$C^*$、块长。
- 开发期看到的全部分数都记入暴露日志。

### 阶段 D：确认实验决策

- 用阶段 L 的估计和阶段 H 的日历，计算有效样本量与所需季数。
- 若在预算与模型版本周期内不可行，报告为"可行性受限的估计性研究"，或重设研究问题。
- 不得临时降低门槛，也不得为追求显著而延长实验。

## 7 确认实验已锁定的规则

### 7.1 主要估计目标

采用事件等权：$\Delta=E_i[d_i]$。估计量为

$$\hat\Delta=\frac{\sum_t S_t}{\sum_t N_t},\qquad S_t=\sum_{i:T_i=t}d_i,$$

其中 $N_t$ 为当日合格事件数，**无事件的交易日也保留**。

**为什么不用每日均值等权**：它对应的是"随机抽一个交易日的平均效果"，不是本研究的目标。示例：5 个高峰日各 150 个事件、25 个稀疏日各 2 个事件时，按日等权会使稀疏日一个事件的权重为高峰日事件的 75 倍，方差（独立情形）为事件等权的 11.1 倍。

### 7.2 推断

- **主推断**：对完整交易日序列 $(S_t,N_t)$ 做联合块自助，每次重算 $\sum S_t/\sum N_t$。块长由开发数据与标签窗口事前选定（候选 10/20/40 个交易日），不得看结果择优。
- **敏感性分析**：对 $z_t=S_t-\hat\Delta N_t$ 做 HAC，$\mathrm{Var}(\hat\Delta)\approx T\cdot\mathrm{LRV}(z)/(\sum_t N_t)^2$。
- **不得**把逐事件的 $d_i$ 直接放入普通 t 检验或标准 DM 检验。DM 处理的是两个竞争预测对同一时间序列的预测误差：它允许序列相关，也允许两个预测在同一时点的误差相关；但不处理同一天多个事件之间的横截面相关。因此 DM 只能用于先聚合成的日序列。
- 若公司跨期相关明显，事前指定公司与时间两个维度的相关检查。

### 7.3 跨季推断

- 逐季估计 $\hat\Delta_g$，再用 $t(G-1)$ 做跨季检验（Ibragimov–Müller）。前提是：各季估计近似独立，且每季事件足够多。
- 跨季的"均值/标准差"须达到以下门槛：$G=3$ 时为 2.48；$G=5$ 时为 1.24；$G=10$ 时为 0.72。
- $G\le3$ 时，除非达到上述门槛，跨季结论一律写为描述性。
- 区分两个不同的问题：
  - (a) **统计推断**：在与已观测各季同一生成过程的季总体上，B 平均是否优于对照；
  - (b) **可迁移性**：对样本未覆盖的市场状态或结构断裂，结论是否仍成立。(b) 无法由任何季间方差证明，只能作为局限报告。

### 7.4 假设层级（固定顺序）

每一步都使用完整的检验水平（同一个 95% 置信区间规则），不拆分 $\alpha$。前一步未拒绝即停止，后续假设不作确认性结论。

| 层级 | 假设 | 含义 |
|---|---|---|
| H1 | $\Delta(B,A)<0$ | 经验利用存在 |
| H2 | $\Delta(B,C^*)<0$ | 优于事前冻结的最佳简单基准 |
| H3 | $\Delta(B,C^*)$ 的 95% 区间上界 $<-\delta_{\min}$ | 增量达到值得工程投入的幅度 |

其余比较（B−U、B−S、B−M、$A_K$−A 等）均为预注册的次要或诊断结果，不得替代主结果。

区间判定规则（沿用原评议 §6，区间记为 [下界, 上界]）：

| 区间位置 | 允许的判断 |
|---|---|
| 上界 $<-\delta_{\min}$ | 有证据支持至少达到最小有用改善 |
| 上界 $<0$，但未满足上一条 | 有改善证据，尚未证实足够有用 |
| 下界 $>-\delta_{\min}$ | 排除了预设幅度的有用改善（不必然表示变差） |
| 区间同时包含有用改善与无改善 | 不确定 |
| 下界 $>0$ | 有变差证据 |

### 7.5 $C^*$ 选择规则（阶段 L 结束时执行并冻结）

- **候选**：U、S、M、$A_K$（$K$ 取事前给定的集合，$K\ge2$）。
- **资格约束**：数值须预注册。示例：费用 ≤ B 的 110%，P95 延迟 ≤ B 的 120%，覆盖率 ≥ 预设阈值。
- 在独立开发数据上按时间顺序做交叉验证，选 Brier 最低者，记录版本哈希后冻结。
- 确认数据出现后不得更换。"这次 M 表现特别好，改用 M 当基准"这类做法不被允许。

### 7.6 成本报告

对每个候选报告成本向量（\$、tokens、延迟 P50/P95）与 Brier，并画出 Pareto 前沿。这是产品决策的依据，不是确认性假设。

### 7.7 运行次数政策

确认实验中，A、B 以及 LLM 类的 $C^*$，采用事前固定、各臂一致的调用次数与聚合方式。不得挑选最好的一次运行，也不得以"解释不满意"为由重抽。

### 7.8 相对 U 的技能分数

显式计算 $BSS_U=1-BS(\text{模型})/BS(U)$，其中 U 为开发期冻结值。不得用 scikit-learn 的 `d2_brier_score` 代替，因为它的空模型用的是评价集自身的类别比例，而不是冻结的 U。

### 7.9 覆盖与回退

沿用原评议 §9：预测增量、服务覆盖（非劣界 $\epsilon_C$ 与绝对底线）、回退策略效果三本账分开记。标签缺失时做界限分析，不得悄悄删除。

### 7.10 样本量来源

正式样本量只来自阶段 L 实测的 $E[d]$、$\mathrm{Var}(d)$、时间依赖结构与覆盖损失。§8 的理论界只作 sanity check。

## 8 可行性理论界（只作 sanity check 与压力分析）

### 8.1 $q$ 是潜变量

每个事件只观测一次 $Y_i$，仅凭历史 0/1 结果无法识别 $\mathrm{Var}(q)$。

对任何确定性预测 $s$ 与已校准的 U，总体改善为 $\mathrm{Var}(q)-E[(s-q)^2]\le\mathrm{Var}(q)$。由此：

- 历史 S 的样本外改善，是 $\mathrm{Var}(q)$ 的**下界**证据；
- S 未胜过 U，不能推出 $\mathrm{Var}(q)$ 小。

**可行性含义**：若 A 近似为已校准的常数，B 相对 A 的最大可能改善就是 $\mathrm{Var}(q)$。H3 的对照是 $C^*$：只要 $C^*$ 的 Brier 不高于 U，B 相对 $C^*$ 的最大可能改善 $E[(C^*-q)^2]$ 也不超过 $\mathrm{Var}(q)$。因此 $\delta_{\min}<\mathrm{Var}(q)$ 是 H3 可能成立的必要条件。例如 $\delta_{\min}=0.005$ 要求 $SD(q)>7.1$pp；接近这一边界时，所需样本急剧增加（§8.2 推论 2）。

### 8.2 理论样本下限（对所有 B 的下确界）

**读法**：本节的数字是任何 B 都不可能少于的独立配对数，即对所有可能的 B 取下确界。它是必要条件，不是充分条件；某个具体 B 的实际需求通常更大。**不能读作"SD(q)=10pp 时 189 对就够"。**

**有效性条件**：

- 事件相互独立；
- B 与对照可以带生成噪声、可以只输出粗刻度，只要噪声在给定 $x$ 时与 $Y$ 独立；
- 采用双侧 5%、80% 功效的正态近似，检验对象为零改善（H1 型）或 $\delta_{\min}$（H3 型）。

**通式**：

$$n\ \ge\ 7.85\cdot\frac{1-K}{K},\qquad K=E\!\left[\frac{(q-c)^2}{h}\right],\qquad h=E[(Y-c)^2\mid x]=(q-c)^2+q(1-q).$$

对照为确定值时，在每个世界里该界都恰为 B 的下确界：沿 $(q-c)/h$ 方向、幅度趋于零的调整可以任意接近它。但这类调整的改善同样趋于零——$E[d]$ 与 $SD(d)$ 同比例缩小，标准化效应趋于常数。下确界由"几乎不改"的 B 逼近，本身没有工程意义。

**证明要点**：令 $r=Y-c$，$v=b-c$，则 $d=v^2-2vr$。取 $W=(q-c)r/h$；给定 $(x,c,v)$，$E[d-dW]=v^2\big(1-(q-c)^2/h\big)\ge0$，故 $-E[d]\le-E[dW]$。又 $E[W^2]=K$，由 Cauchy–Schwarz 得 $E[d]^2\le K\,E[d^2]$。

**推论 1（H1 型；对照为已校准常数 U；与 q 的分布形状无关）**：因 $h\ge\min(U,1-U)^2=:m^2$，

$$n\ \ge\ 7.85\cdot\frac{m^2-V}{V},\qquad V=\mathrm{Var}(q).$$

U=0.5 时 $h\equiv0.25$，此式对任意 q 分布恰为下确界。

**推论 2（H3 型：要求改善 ≥ $\delta_{\min}$；对照为已校准 U）**：B 相对 U 的改善 $I\le V$，且 $\mathrm{Var}(d)\ge I^2(1-K)/K$，故

$$n\ \ge\ 7.85\cdot\frac{(m^2-V)\,V}{(V-\delta_{\min})^2}\ =\ \text{推论 1}\times\Big(\frac{V}{V-\delta_{\min}}\Big)^2 .$$

$V\le\delta_{\min}$ 时，H3 对任何 B 都不可能为真。U=0.5 时该界可达：q 只取 0、0.5、1，B 为 oracle 时恰好取等。

**对照比 U 更准时**（如 $C^*$，其 Brier 不高于 U）：若所有 $q\in[0.3,0.7]$，把两个推论中的 $m^2$ 换成 0.21，下限仍成立（此时 $h\ge q(1-q)\ge0.21$；对照可带噪声）。

| $SD(q)$ | 15pp | 12pp | 10pp | 8pp | 7pp | 5pp | 3pp | 2pp |
|---|---|---|---|---|---|---|---|---|
| 推论 1，U = 0.50 | 80 | 129 | 189 | 299 | 393 | 778 | 2,173 | 4,898 |
| 推论 1，U = 0.52 | 73 | 118 | 173 | 275 | 362 | 716 | 2,002 | 4,514 |
| 推论 2，U = 0.50，$\delta_{\min}$ = 0.005 | 132 | 302 | 754 | 6,244 | 不可能 | 不可能 | 不可能 | 不可能 |

**同一下限、不同需求**（U=0.5，SD(q)=10pp；H1 型下限 188.4，H3 型下限 753.5）：

| 世界 | B | 对零（H1） | 对 $\delta_{\min}$=0.005（H3） |
|---|---|---|---|
| $q\in\{0.4,0.6\}$ | oracle，$p=q$ | 753.5 | 3,014 |
| $q\in\{0.4,0.6\}$ | $p=0.499/0.501$ | 190.3 | 不可能（改善仅 0.0002） |
| $q\in\{0.4,0.6\}$ | 调整幅度趋于 0 | 趋于 188.4 | 不可能 |
| $q\in\{0.4,0.6\}$ | H3 最优（$p\approx0.43/0.57$，网格搜索） | — | 2,196 |
| 4% 的 $q\in\{0,1\}$，其余 $q=0.5$ | oracle | 188.4（恰为下限） | 753.5（恰为下限） |

两种世界具有同一理论下限：极端世界中 oracle 恰好达到它，两点世界中只有趋于零的调整才逼近它。两点世界 oracle 的 H1 需求（753.5）与 H3 下限数值相同，是 $\delta_{\min}=V/2$ 时的巧合。

**用途与边界**：

- 生成噪声、粗刻度、覆盖损失、要求 $\delta_{\min}$，都只会让实际需求更大，所以该下限在这些条件下仍是有效底线；覆盖损失还要把所需候选机会数再除以覆盖率。
- 事件相关通常也使需求更大；但若 B 的调整方向平衡，§8.4 单因子模型下 DEFF $=1-\rho_Y<1$，下限可被略微突破。
- q 不可观测，数据只能给出 V 的下界（§8.1），而两个下限都随 V 递减，所以本表只能按假设的 SD(q) 查阅，不能由数据直接算出。
- 正式样本量只来自阶段 L 的实测（§7.10）。

**数值核验**：

- 对照为已校准 U（24,882 个随机世界，含 $q=0$ 或 1 的事件与带噪声的 B）：实际需求与推论 1 之比最小 1.0002；U=0.5 的对称世界中，世界内下确界与推论 1 完全相等；推论 2 在 $\delta_{\min}$ = 0.002 / 0.005 / 0.01 下的最小比值为 1.011 / 1.014 / 1.020。
- 对照非恒定（25,970 个世界）：与通式之比最小 1.0020。
- 对照比 U 更准（$q\in[0.3,0.7]$，对照可带噪声）：H1 型最小比值 1.41，H3 型 2.51。
- 此前以 $c_0=\min q(1-q)$ 表述的版本，在 q 含极端值时会退化为空界，已由本版替代。

### 8.3 生成噪声的影响

- **A/B 比较**：噪声对 $E[d]$ 的贡献为 $\sigma_B^2-\sigma_A^2$，两臂相等时为 0。噪声的主要作用是增大 $\mathrm{Var}(d)$。
- **与其他基准比较**：对确定性基准 U、S，噪声的贡献为 $+\sigma_B^2$；对 M，为 $\sigma_B^2-(1-w)^2\sigma_A^2$。取 $K$ 次平均，可把单臂噪声项降为 $\sigma^2/K$。
- **示例**（$q=0.6$，A=0.50，B=0.51，事件独立）：每臂独立噪声为 0 / 1 / 2 / 3 / 5pp 时，所需配对分别为 209 / 642 / 1,943 / 4,115 / 11,093。

### 8.4 设计效应（仅用于规划）

在可交换的单因子模型下（$a$ 固定、$u$ 为确定值）：

$$\mathrm{DEFF}=1+\rho_Y\,(m\,c-1),\qquad c=\bar u^2/\overline{u^2}.$$

模拟（$m=50$，$\rho_Y=0.064$）：

| 方向一致性 $c$ | 模拟 DEFF | 公式 DEFF |
|---|---|---|
| 1 | 4.17 | 4.12 |
| 0.25 | 1.74 | 1.73 |
| 0 | 0.93 | 0.94 |

$\rho_Y$ 来自阶段 H，$c$ 来自阶段 R。

**局限**：

- 若各股票的因子暴露正负不一，应改用 $u$ 与暴露的相关；
- 效果随市场状态变化，会额外增加季级方差；
- 最终推断按 §7.2–7.3 执行，不使用此式。

### 8.5 无标签上界 $C_i$ 的定位

$C_i=\max\{a^2-b^2,(1-a)^2-(1-b)^2\}$ 是这批固定输出的严格改善上界。但运行噪声本身就会让它通过：零效应时，每臂噪声为 0.5 / 1 / 3pp，对应的 $\bar C$ 为 0.0056 / 0.011 / 0.034，均大于 $\delta_{\min}=0.005$。因此它只作送达检查，不作效果闸。
