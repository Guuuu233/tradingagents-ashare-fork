# TradingAgents 首个组织经验实验：文献与统计优化评议

检索与撰写：2026-09-22 至 2026-09-23。对象：2026-09-21《首个组织经验实验协议草案》。

**判断：保留两条 LLM 实验臂、前瞻确认和整包干预；优先补足经验对象、低成本替代基准、相关性推断、覆盖约束和样本量可行性。首轮不引入在线自我更新。**

本文是研究设计建议，不是已完成的预注册、实施验收或真实效果报告。原草案未修改，未运行产品分析、真实数据采集或交易。这里的数值例子和模拟均有明确标注。文献检索截至评议日，侧重 2023–2026 年智能体与金融研究，同时使用经典统计文献；这是针对方案的定向综述，不声称穷尽所有研究。

## 一、研究定位：先验证经验能否被使用，再验证经验能否被积累

原草案的问题有价值：在同一机会、同一市场结果下，向冻结的 TradingAgents 提供“预期比较＋市场基率＋命题上下文”，能否改善 T+10 行业相对概率？这一步可以明确失败，也可以控制成本，适合作为第一项实验。

但应把“组织经验”分成四个可区分的研究对象：

| 层次 | 实际问题 | 本轮能否回答 |
|---|---|---|
| F0：数据与测量 | 当时的信息是否可信，概率与标签是否同义？ | 必须先通过 |
| F1：冻结经验利用 | 既有经验包能否改善当前决策？ | 本轮主要问题 |
| F2：经验形成 | 哪种总结、筛选和压缩方式能形成更有用的经验？ | 本轮不能归因 |
| F3：持续更新 | 接收新反馈后，经验更新是否改善后续表现，并抑制错误积累？ | 另开协议 |

建议名称：**“冻结组织经验包对 TradingAgents 概率预测的增量实验”**。这里的组织经验应定义为“由可审计历史事件形成、带适用条件与失效条件、能被后续决策调用的版本化经验”，而不只是一般资料摘要。

这一区分有前沿研究依据。Evo-Memory 把经验利用放进连续的 search–predict–evolve 流程；MemoryArena 检查记忆能否支持相互依赖的后续行动；EvoMemBench 则显式区分单次任务内部和跨任务的知识、执行经验。[4–6] 因此，冻结后测试其迁移价值是有意义的一步，但不能替代持续学习实验。

## 二、文献实际支持什么

下表依据已取得论文的相关方法、结果和局限段落整理。预印本与已发表研究分别标识；没有将搜索摘要或模型生成的检索概览当作效果证据。

| 研究 | 可借鉴内容 | 不能照搬的结论 |
|---|---|---|
| FinMem，2023；FinCon，2024 [1–2] | 分层记忆、经理与分析师分工、跨轮次信念更新；说明经验表示和调用具有可实现的技术路径 | 历史美股收益不能用作本实验的先验效应大小，更不能保证 A 股前瞻增益 |
| TradingAgents，2024/2025 [3] | 原框架的专业角色和辩论链；实验应保留真实底座 | 文中主要模拟区间为 2024 年第一季度的科技股；输入按日期过滤，并不能单独证明预训练参数没有未来信息 |
| Evo-Memory，2025，2026-05 修订 [4] | 将经验检索、使用、更新区分；记忆方法在不同任务上的收益不一致 | 数学、工具和交互任务的正确反馈，与金融噪声收益反馈不同 |
| MemoryArena，2026-02 [5] | “记住”与“帮助下一步行动”分别评估；外部记忆并非普遍优于完整历史上下文 | 对话、规划和推理任务上的结论不能直接外推到股票概率预测 |
| EvoMemBench，2026-06 版本 [6] | 保留原始证据是强基准；经验迁移与知识修订需要独立测试；统计总 token 成本 | 不能因为某种记忆架构更复杂，就预设它更有效 |
| STALE，2026-05 [7] | 识别旧经验失效，与真正改变后续行动不是同一种能力；应记录有效期及反例 | 其主要是个人助手的隐含状态冲突；不能据此量化金融市场中的失效率 |
| AgeMem，2026-07 版本 [8] | 将存储、检索、更新、删除作为可训练操作，是后续研究方向 | 它包含强化学习训练，不是给现有 TA 接一个记忆库即可复现的方案 |
| ForecastBench，2024/2025 [9] | 在事件尚未结算时封存概率，后续依据真实结果评价 | 通用预测题的成绩不是本实验的金融效果先验；其暂未结算题的代理评价也不应替代本实验的最终标签 |
| Gao、Jiang、Yan，2026-06 版本；Glasserman、Lin，2023 [10,18] | 金融 LLM 的参数记忆污染值得单独诊断；匿名化会同时改变信息和干扰 | 匿名化改善、诊断未拒绝或训练后表现下降，都不能单独认证“没有前视” |
| Gneiting、Raftery；Diebold、Mariano；Cameron、Miller [11–13] | 严格适当概率评分、配对损失差、时序与聚类相关推断 | 不能直接对全部公司事件使用独立样本标准误 |
| CORP 校准研究 [14] | 可靠性图不应靠随意分箱决定结论；校准需要不确定性表达 | 原文的区间方法要求独立或至少可交换样本，不能原样套到重叠金融事件 |
| 中国 PEAD 研究及 FinNLP 2025 论文 [15–16] | 市场反应、注意力与预期差值得研究；公告时点和文本可用时点必须分开 | 60 日漂移、美股 10-Q、公告后三日信号，都不是本草案 T+10 首次预告问题的直接证据 |

另外核读了 Look-Ahead-Bench（2026）[17]。其五只大型科技股、两个半年区间的设计可用于提出诊断问题，但“跨期收益衰减”也可能来自市场状态变化，不能唯一识别参数泄漏。本文不采纳其商业 PiT 模型表现作为选型依据。

## 三、优化一：明确两道时间截止，并避免改变预测对象

需要同时冻结两条不同的时间线：

1. **事件前参考预期截止**：卖方预测的版本必须能证明在首次预告之前已存在。
2. **决策输入截止**：首次预告及其他合法信息，必须在 A/B 输入包冻结前已经实际可用。

两者不是同一时刻。公告发生后才拿到一份旧日期研报，只有在其旧版本内容可独立核验时，才可能证明“事前参考预期”；不能把公告后的修订值配上旧日期。

形式化地，设首次事件时点为 \(\tau_i^E\)，决策截止为 \(\tau_i^D\)：参考预测需满足“版本存在时间 < \(\tau_i^E\)”，所有输入需满足“合法可用时间 ≤ \(\tau_i^D\)”。基率的训练事件还必须在实验冻结时点之前完成标签结算并取得合格记录。时间精度不足时使用保守资格规则，不伪造顺序。

PEAD 文献提示公告后价格反应可能含信息，但必须看其是否在原定截止前已经观察到。[15–16] 若为了观察三天价格而把入场推后三天，研究对象就变了。首轮不要因此变更既有 T+10 契约；可以记录截止前已发生的反应，作为事前指定的解释变量或次要分层。

另一个必要边界：管理层预告区间不是实际利润，也不是具有名义覆盖率的统计置信区间。卖方分散度同样不能直接当成“真实市场预期”的置信区间。保留中位数、区间、机构数、机构预测年龄与分散度，首轮不强行生成“超预期百分比”。

## 四、优化二：把经验包写成能够审核的对象

首轮建议选择**一个事前固定的决策节点**注入。若选择最终经理，可共享注入之前、确实不受处理影响的上游结果；两条分支分别运行该节点及其所有受影响的下游。这样降低成本，但结论必须表述为“该决策节点使用经验包的增量”。如果目标是分析师到经理全链路的组织效应，就需要重跑全部受影响链路，不能靠共享上游冒充。

每个包至少包含：

| 字段 | 含义 |
|---|---|
| opportunity_id、contract_version | 唯一机会及目标标签契约 |
| event_version、event_at、cutoff_at | 首次预告版本与两类时间边界 |
| forecast_range、consensus_definition | 区间及利润口径，保留单位和归属 |
| consensus_median、coverage、age、dispersion | 参考预期及其可信度描述 |
| surprise_class | 高于、覆盖、低于；不可比单列 |
| base_rate、support_n、support_dates | 收缩后概率、原始事件数、时间支持范围 |
| base_rate_rule、fallback_level | 估计和回退来源，区分无数据与弱证据 |
| thesis_id、version、provenance | 命题及其来源，明确人工制定还是历史经验归纳 |
| applicability、counterevidence、invalidation | 适用条件、反例、失效条件 |
| evidence_ids、content_hash | 可追溯原始证据 |

不让 LLM 自己计算基率或选择“最好看的”历史条件；由冻结的统计程序生成数字，LLM 负责在上下文中使用。提示词明确说明：基率不是结论，命题不是已证实因果机制，模型可以有证据地偏离它。

推荐首轮采用固定结构，不追求复杂记忆图或自动删除规则。保留原始证据索引，减少多次摘要造成的信息损失。这与 MemoryArena、EvoMemBench 所发现的“记忆压缩并非总是优于原始上下文”一致。[5–6]

两臂都应保留完整合法底座，避免 B 的新包挤掉 A 原有材料。B 多出的输入长度、延迟和费用是产品干预的一部分，需如实报告。若将来要识别“经验内容本身”而不是整个附加上下文处理的效果，再增加长度匹配对照；本轮无需为此增加第三条 LLM 链。

## 五、优化三：保留两条 LLM 臂，增强便宜的统计比较对象

### 5.1 加入无条件概率基准

除 A、B 和原有条件基率 S，增加开发期冻结的总体概率 \(p_0\)。它回答：复杂系统是否超过“这种机会一般有多大概率跑赢行业”的常识基线。

固定 \(p=0.5\) 可以作为刻度，但不应假设合格事件的行业相对正收益概率必然是 50%。S 优于 A 只说明相对 A 更好；S 还需与 \(p_0\) 比较，才有证据讨论条件信息的价值。

### 5.2 对小样本基率做收缩，避免分桶膨胀

首轮先使用“高于、覆盖、低于”三个核心类别，行业、机构数、年份等不同时交叉切成大量小格。一个低成本收缩估计是：

$$
\widehat p_g=\frac{k_g+\kappa p_0}{n_g+\kappa}.
$$

其中 \(n_g\) 为合格成熟事件数，\(k_g\) 为其中行业相对正收益数，\(\kappa\) 为收缩强度，仅在过去的开发数据中选择并冻结。

**示例，不是真实数据**：一组 10 个事件中 7 个为正，直接报 70% 很不稳定；若 \(p_0=0.52,\kappa=20\)，得到 58%。这个例子说明如何抑制小样本极端值，不是在推荐实际 \(\kappa=20\)。

该公式在独立 Bernoulli 与 Beta 先验模型下是后验均值；对有相关性的金融事件，不能把 \(n_g\) 当作独立信息量，并直接引用普通 Beta 后验区间。首轮可把它作为正则化预测器，不确定性另按日期区块审计。经验样本不足时，按预定层级回退到全体合格过去事件；连该总体都没有可信数据时，返回不可估计。

### 5.3 增加“A＋S 的机械组合”基准

这是比新增 LLM 实验臂更有信息量的便宜比较：

$$
p_i^{mix}=(1-w)p_i^A+w p_i^S,\qquad 0\le w\le1.
$$

在一个独立开发/校准集上，最小化 Brier 的权重为：

$$
\widehat w=\operatorname{clip}_{[0,1]}
\left(\frac{\sum_i(p_i^S-p_i^A)(Y_i-p_i^A)}
{\sum_i(p_i^S-p_i^A)^2}\right).
$$

分母为零时预设 \(w=0\)。生成开发期 S 时，只能用更早且标签已成熟的数据；不能用整个开发集拟合 S 后，又在同一批样本上选择 w。可以采用按时间顺序的开发折生成样本外预测，然后冻结 w。检验集绝不能参与权重选择。

如果 B 优于 A，但不能证明优于这个机械组合，产品仍可能有可用性价值，但当前证据还没有证明“把经验交给 LLM 使用”超过简单融合。即使 B 优于组合，也只能说超越了这个具体基准，不能直接归因于推理机制。比较对象的信息与成本差异应随结果披露。

原表中的“B 优于 A 但不优于 S，很可能只是在重新表达基率”建议删除。未检出差异不能识别生成机制，也不等于证明等效。

## 六、优化四：保留 Brier 主指标，但把成功标准写完整

令同一事件的结果为 \(Y_i\in\{0,1\}\)，两臂概率为 \(p_i^A,p_i^B\)。主观测量为：

$$
d_i=(p_i^B-Y_i)^2-(p_i^A-Y_i)^2,\quad
\widehat\Delta=\frac1n\sum_i d_i.
$$

负数表示增强组改善。Brier 的依据不只是常用：若真实条件概率为 q，预测 p 的期望损失为

$$
\mathbb E[(p-Y)^2\mid q]=q(1-q)+(p-q)^2,
$$

所以在诚实评价的前提下，报告真实条件概率能唯一最小化期望损失。[11]

还可以把每个事件的变化写成：

$$
d_i=(p_i^B-p_i^A)^2+2(p_i^B-p_i^A)(p_i^A-Y_i).
$$

它说明，偏离 A 本身会带来一个非负项；只有修正方向足够贴近 A 的真实误差，改变概率才产生净收益。可报告“修正了多少、在哪些事前指定类别修正有效”，但这仍是事后诊断，不是因果推理证明。

预注册最小有用改善 \(\delta_{min}>0\)，并报告 \(\Delta\) 的 95% 区间 [L,U]：

| 区间位置 | 允许的判断 |
|---|---|
| \(U<-\delta_{min}\) | 有证据支持至少达到最小有用改善 |
| \(U<0\)，但未满足上一条 | 有改善证据，尚未证实足够有用 |
| \(L>-\delta_{min}\) | 区间排除了预设幅度的有用改善；这不必然表示变差 |
| 区间同时包含有用改善与无改善 | 不确定，不能说“无效”或“有效” |
| \(L>0\) | 有变差证据 |

“0.01 Brier 改善”是评分损失减少 0.01；例如从 0.25 到 0.24 为相对减少 4%，**不是股票收益提高 1%，也不是准确率提高 1 个百分点**。

首轮只保留一个主要效果假设 B−A。其他基准比较和事前分组可以报告区间，但不得挑选其中最漂亮的一项取代主结果。若希望 B−S、B−mix 也成为正式确认性结论，须事前固定检验顺序或分配多重检验错误率。

## 七、优化五：以日历时间处理相关性，不把事件数当独立样本数

配对设计控制了同一机会的难度差异，却没有消除三个相关来源：同日市场冲击、相邻事件收益窗口重叠、同公司重复出现。[12–13]

不建议直接对所有 \(d_i\) 做普通配对 t 检验或逐条重采样。首轮可采用如下分析计划：

1. 主要估计量仍为事件等权平均，保留所有合法配对，不为了“独立”任意删掉多数重叠机会。
2. 在完整交易日日历上，保存 \(S_t=\sum_{i:T_i=t}d_i\) 和 \(N_t\)，没有事件的交易日也保留。
3. 以连续交易日区块共同重采样 \((S_t,N_t)\)，每次重新计算 \(\sum S_t/\sum N_t\)。这样保留事件等权目标；直接平均每日均值会悄悄改成日期等权目标。
4. 区块长度用开发期依赖结构与实际标签窗口选择并预注册。可以把 10、20、40 个交易日作为设计阶段候选，但不能看正式结果后择优。T+10 并不保证相关性到第十天恰好消失，退出展期还可能延长依赖。
5. 以日历序列的长期方差/HAC 推断作为预定敏感性检查。若跨年度同公司相关性明显，再预定公司与时间的多维相关检查；“公司×日期”拼接成一个 ID 不等于分别处理两种相关。

上述区块方法依赖足够长的观测跨度与适当的弱依赖条件，不是对任意结构变化都有效。若只有一小段披露高峰，即使数百家公司也无法支持广泛的跨市场状态结论。不能机械宣称“有 30 个块就一定足够”；应在设计模拟中检查区间覆盖和误报。

### 本次统计模拟：相关性会造成多大影响

这是方法演示，不是 TA 回测。构造 40 个相互独立的簇，每簇 20 条事件；簇内标签相关系数 0.10。A 总是报 0.45，B 总是报 0.55，结果边际概率为 0.5，因此二者真实 Brier 完全相同。重复 10,000 次：

| 方法 | 名义双侧误报率 | 模拟实际误报率 |
|---|---:|---:|
| 将 800 条事件视为独立，用普通标准误与正态临界值 | 5% | 25.72% |
| 对 40 个簇均值推断，使用簇间标准误与 t(39) 临界值 | 5% | 5.35% |

两项模拟比例的蒙特卡洛标准误分别约 0.44 和 0.23 个百分点。第二种方法在这个设定下接近名义水平，但该模拟尚未包括相邻日期依赖、季节性或公司跨期相关，不能作为实际时间区块方案已经验收的证据。

可复现设定：随机种子 20260922；每簇 \(\theta_g\sim Beta(4.5,4.5)\)，簇内 \(Y_{gi}\mid\theta_g\sim Bernoulli(\theta_g)\)，不同簇独立；使用 NumPy default_rng，Python 3.14.6 / NumPy 2.5.1。本次另复算了 Brier 差分恒等式、重复运行恒等式及机械融合权重，数值误差在浮点精度范围内。

## 八、优化六：用效应、方差和时间覆盖共同决定能否做得起

在独立近似下，以双侧 5% 显著性和 80% 功效检出真实改善 \(\delta\)，需要的有效配对数近似为：

$$
n_{eff}\approx\frac{(1.96+0.842)^2\sigma_d^2}{\delta^2}.
$$

这里 \(\sigma_d\) 是配对损失差的标准差，不是收益率波动，也不是某一臂 Brier 的标准差。

**以下全部是假设情景，不是实测所需样本量：**

| 假设 \(\sigma_d\) | 真实 Brier 改善 \(\delta\) | 近似独立有效配对数 |
|---:|---:|---:|
| 0.10 | 0.005 | 3,140 |
| 0.10 | 0.010 | 785 |
| 0.10 | 0.020 | 197 |
| 0.15 | 0.010 | 1,766 |

简单等大小聚类下，设计效应可用 \(DEFF\approx1+(m-1)\rho\) 做粗略演示。若 m=25、\(\rho=0.03\)，DEFF=1.72，再假设最终配对覆盖为 85%，785 个有效配对约对应 1,589 个候选机会。真实簇不等大、还存在时序相关时，应以保留日历结构的模拟计算，不能把这个粗略公式当成最终功效设计。

还有一个容易被忽略的区别：上表检验的是相对零改善。若要求 95% 区间整体低于 \(-\delta_{min}\)，功效计算中的有效距离应为 \(\delta_{true}-\delta_{min}\)。例如要求至少改善 0.01，而预期真实改善为 0.02，检验距离仍为 0.01；不能直接使用表中 0.02 那一行。真实效应恰好在门槛上时，不可能设计出 80% 概率严格跨过该门槛的标准检验。

建议先做两步设计工作：

- 对约 50 个按事前日期与股票范围抽取的发现事件做数据审计，统计每一层资格损失。这个数只用于初步工作量规划，不是覆盖率精确估计或统计充分性门槛。
- 在 40–80 个独立于确认集的开发机会中，估计成本、逾期率、概率差异和运行噪声；其中 10–20 个机会各跑 3 次，判断随机生成是否占主要方差。数量是可调的预算建议，不能据此宣布有效。历史 LLM 的污染可能使方差和效应估计失真，因此对前瞻功效需做保守情景，并优先使用不进入确认集的前瞻设计试点。

如果覆盖漏斗和事件日历表明，在模型可合理维持的版本周期内根本凑不到需要的有效样本，应把这一轮定位为可行性/估计性试点，或者事前重设研究范围；不能临时降低成功门槛，也不能不停延长直到显著。

## 九、优化七：用覆盖门约束条件性 Brier，再单独评估失败回退策略

草案的共同成功子集评分是可接受的，但它只回答：“两臂都能按时给出概率且标签可结算时，谁更准？”缺失很可能与复杂、低覆盖或极端事件相关，不能默认随机。

建议保留三个分开的结果：

1. **预测增量**：合格配对集的原始 Brier 差及相关性调整区间。
2. **服务覆盖**：\(C_A,C_B\)、配对覆盖和原因分布。设 \(D_i=1\{B有效\}-1\{A有效\}\)，在全机会集上用同一时间相关框架估计 \(\mathbb E[D_i]\)。以事前容许下降 \(\epsilon_C\) 判断非劣，同时设置绝对覆盖底线。两臂同样糟糕，不能因为差值接近零就过关。
3. **回退策略效果**：若需要衡量产品实际输出，预先定义运行失败时的显式回退概率：

$$
p_i^{a,policy}=
\begin{cases}
p_i^a,&\text{按时有效};\\
p_i^S,&\text{失败且 S 合格};\\
p_0,&\text{S 不可用但冻结的总体基准合格}.
\end{cases}
$$

该规则需在入场前确定并记录。若连 \(p_0\) 都没有资格，则策略也无有效概率。这是一个真实定义的备用预测策略，不是事后给失败的 LLM 填 0.5。其成绩必须标为“系统含回退策略”，不能冒充原始模型 Brier。

概率缺失与收益标签缺失还需分开。若预测已封存但标签未知，可以做界限分析，而非悄悄删掉。例如同一机会的两个概率 p、q 已知：

$$
d(Y=0)=q^2-p^2,\qquad d(Y=1)=q^2-p^2-2(q-p).
$$

未知标签对应的损失差落在这两个值之间，可直接聚合得到较紧的最坏/最好界限。若只用一般 \(d\in[-1,1]\)，则已知比例 c、已知部分均值 \(\bar d_{obs}\) 对应的全体均值范围为

$$
[c\bar d_{obs}-(1-c),\ c\bar d_{obs}+(1-c)].
$$

例如 c=0.95、\(\bar d_{obs}=-0.01\)，范围为 [-0.0595, 0.0405]，符号仍不确定。**这个界限要求完整目标中的损失差已有定义，只是尚未观测；不能用来替根本没有输出或回退定义的模型凭空构造“全量 Brier”。**

逆概率加权只能作为有明确假设的敏感性分析：需要缺失在已观测变量条件下可忽略、选择概率有正下界且模型适当。首轮不建议把复杂缺失模型作为唯一救场办法。

## 十、优化八：固定随机运行政策，避免把重复调用当成新样本

一次机会重复调用 R 次，得到 R 个概率，并不意味着获得 R 个独立市场结果。它主要估计算法的运行噪声。

还必须区分两种策略：

$$
\frac1R\sum_r(p_{ir}-Y_i)^2
=(\bar p_i-Y_i)^2+\frac1R\sum_r(p_{ir}-\bar p_i)^2.
$$

左边是随机单次运行的平均损失；右边第一项是 R 次概率平均后的集成策略损失。集成通常因平滑而降低平方损失，同时增加费用；它已经是另一种产品策略。

建议主实验采用两臂一致的固定调用次数。若正式策略是单次运行，重复仅用于独立设计试点；若决定使用三次集成，则 A、B 同样集成，提前锁定聚合方式与三次运行失败政策，并按事件聚合后推断。不得选出最好的那次，也不以“解释不满意”为由重抽。

相同 seed 或 temperature=0 不能被当成跨供应商、跨时间完全可复现的保证。保存实际输出、时间、模型标识、重试记录及全部输入材料。两臂运行顺序事前随机化或交错，减少服务拥堵和后端漂移造成的系统差异；这不能替代市场事件相关性处理。

## 十一、优化九：让机制诊断帮助解释失败，但不替代效果检验

首轮无需增加确认性 LLM 臂，可以在开发阶段加三类小规模检查：

- **信息使用检查**：是否准确引用预期区间、样本支持及失效条件；基率与文本数字是否一致。
- **适用性检查**：给不匹配年份、行业范围或已失效命题，观察模型是否识别不适用。参考 STALE 的“识别”和“行动”分离思路，分别看它是否指出问题，以及最终概率是否仍盲从。[7]
- **扰动检查**：在明确标为合成测试的材料中改变有效样本量、区间宽度或命题支持，观察概率与解释是否有合理响应。这检验使用能力，不强行要求“超预期越大，股价概率必然越高”。市场可能已定价，命题也可能不适用。

如需区分语义内容和单纯提示长度，可在开发子集比较空包、长度匹配无关材料或打乱经验包；这些是有成本和潜在副作用的诊断，不应混入主要确认集。自述理由或引用命题，不足以证明真正的内部因果推理。

校准作为次要诊断，建议报告概率分布与可靠性图，而不以任意十等分箱 ECE 决定成败。可参考 CORP，但原文明确提醒其不确定性方法的独立/可交换假设。[14] 在本实验中，校准图先作为描述；任何金融相关数据的区间做法都需另行验证。严禁在测试集拟合校准器后，再把同集更好的 Brier 当成可部署成绩。

## 十二、优化十：把反馈更新推迟到独立的第二阶段

当前确认阶段不要根据新收益改经验库、命题或检索权重。这既保持可归因性，也避免把偶然获利固化为“成功经验”。金融收益是噪声反馈，单次对错不能证明推理过程正确。[1–2,4,8]

后续可以研究批次更新：在一个完整前瞻 cohort 标签成熟并审计后，形成候选经验版本；新版本只在下一批未见事件中测试，冻结版继续作为并行基准。记录生成、选择、拒绝、修订和废弃的全部候选，不只保留成功命题。

即使采用分批更新，比较对象也已变成两种历史依赖的策略；两个策略的内部状态、成熟标签可见性和版本都要独立管理。不能简单对“更新前后”的分数做比较，因为市场时期也同时变化。若本轮历史基率都无法合格，第一步应是建立前瞻证据池，而非临时让 LLM 编出经验。

| 原章节 | 优先修改 | 完成标准 |
|---|---|---|
| §1 研究问题 | 明确 F1 冻结经验利用与决策节点 | 问题、干预、评价对象一一对应 |

| §5 对照与基准 | 增加 \(p_0\) 与机械融合；收紧解释表 | 不增加额外 LLM 生产链即可生成基准 |
| §6 基率与命题 | 收缩规则、少量分桶、命题来源与失效条件 | 没有临时选桶与自引用 |
| §7 时间状态机 | 标记源事件、输入可用、预测封存和标签成熟 | 不通过移动入场修补超时 |
| §8 评价 | 原始概率、覆盖、回退策略分账；有用差异与区间判据 | 能分别回答更准、覆盖不降、系统是否值得用 |
| §9 样本与停止 | 有效样本量、日历跨度、相关性模拟与成本 | 先证明研究能在预算和版本周期内完成 |
| §10 验收 | 增加统计程序的零效应、相关性、缺失与集成场景检查 | 错误方法在模拟中可被识别 |
| §12 版本治理 | 记录所有测试信息暴露，包括标签和分组收益 | 未看 A/B 分数也不自动获得修改确认设计的自由 |

推荐顺序：**数据可行性审计 → 完整经验包示例 → 开发试点与统计设计 → 锁定参数和版本 → 前瞻确认 → 独立分析 → 决定是否进入消融或持续学习阶段。**

其中前三步的产物应是可审核的包、覆盖漏斗、成本与方差情景，不应把“搭好更多智能体”当作进度指标。

建议保留固定日历结束、最低机会数量与预设预算上限。如果截止时信息不足，报告“不确定”；不为获得显著性自动续期。首轮不必引入复杂的序贯显著性机制。如将来确需边看边停，应单独设计适用于依赖数据的序贯方法，不能直接反复计算普通 p 值。

## 十四、研究问题卡

**问题**：在有合格事前卖方参考预期、首次年度业绩预告可核验的事件子总体中，冻结经验包能否改善指定 TA 节点对既定 T+10 行业相对结果的原始概率？

**假设**：配对 Brier 差为负，并达到事前定义的最小有用改善；覆盖不低于预设非劣界限和绝对底线。

**现有依据**：智能体经验使用与迁移在其他任务已有研究路径；金融事件预期差具备经济学动机；严格适当评分与相关性推断提供评价工具。没有直接证明本项目该干预前瞻有效的结果。

**缺少依据**：利润口径与事前版本的真实可得性；年度首次事件覆盖；基率的合格历史支持；\(\sigma_d\)、运行噪声、日历依赖、成本与模型版本稳定期。

**支持条件**：相关性调整后的区间越过有用改善门槛，覆盖合格，缺失/版本/时间审计没有破坏解释；若讨论超越机械融合，另需相应预注册比较。

**反对或降级条件**：区间排除有用改善；覆盖明显下降；增益在便宜融合后消失；效果只存在于某个事后挑选分组；或者关键数据资格无法证明。

**最小下一步**：完成按事前抽样规则选择的一批发现事件的覆盖审计，并制作一份可逐字段核对的经验包。随后估计可完成的有效样本范围，才决定正式观察期。

**当前决策**：可进入设计试点，不把本文当作正式确认实验已获实施或部署许可。
