## 一、项目是什么，要做成什么

### 产品定位（07-31 定下，至今未变）

这是一个基于开源 TradingAgents 改造的 A 股多智能体投研系统。15 个角色按固定链路工作：

7 名分析师 → 多空研究员辩论 → 研究经理裁决 → 交易员计划 → 激进 / 中性 / 保守三方风控辩论 → 风控总监。

产出是结构化报告，带数据来源、数据日期和缺口声明。系统不下单，也不保证收益。

这个定位来自一个朴素的事实：早期自建工具的方向命中率约 50.5%。所以项目从一开始就不以“预测涨跌”自居，而是把“有数据就标来源，没数据就写不可用”做成了硬规则（`AGENTS.md` §3）。

### 上线后首份真实报告说明了什么（4390ddfd，贵州茅台 2026-09-23）

- 报告共登记 205 个价格，其中 20 个驱动决策的价格说不清来源，所以整份报告被拦下。这 20 个里：
  - 16 个是模型自己写的交易价位，没有注明依据。有的是指标值被四舍五入后写进去的（例如布林下轨实际是 1238.53，报告写成 1238.50）。
  - 4 个是抽取误报：差额（上行空间、滑点）和非本股价格（飞天茅台批发价）。
- 3 个被判为“估值推算、可豁免”的价格里，有 2 个判错：一个是情景价位，一个是技术指标值。
- 结论：先收紧判定（DAV-1235），再让模型在生成时标注价格来源。顺序不能反，否则误豁免会变成假的干净样本。

- **cohort**：决策模型、证据契约、价格口径三者的版本组合。不同 cohort 不得混算。

- **derived_estimate（估值推算）**：由估值公式算出来的价格（例如“20 倍 PE 对应 1274 元”）。它不是行情坐标，不承担口径和日期的问责，但也不能用作可执行价位。
- **B2 / B3**：09-21 冻结的两批分层历史重放，每批 12 条，共 24 条。
- **W0–W4**：DAV-1225 的零 token 分层重算，每层在上一层基础上叠加一种修正。
- **ABSTAIN / WAIT / NO_TRADE**：拒判 / 等待确认 / 不交易。三者都不进入回测、校准和 H1b 计数。
- **RT-FULL**：全量回归测试。改产品代码必须跑，且不得新增失败。
