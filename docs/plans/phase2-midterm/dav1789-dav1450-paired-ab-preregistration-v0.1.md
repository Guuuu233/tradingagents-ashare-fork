## 4. 主指标定义：对齐、多空中性、偏空、覆盖

**主读数节点为经理原始机读裁决（新增处理前后共同节点，既有门之前）**；最终门后方向/可执行动作另表。不能用下游门拦截掩盖提示词不合规。每臂每档都列原始BULL、BEAR、NEUTRAL、ABSTAIN、INVALID_RUN、执行失败、机读缺失；后四类不合并成中性。

冻结审核时确定机读方向字段及同义值规范化映射，两臂共用。引用校验使用该次原始经理输出的已采纳账本，另以最终合法裁剪账本作敏感性对照；不将后处理更改账本冒充模型原始采纳。已采纳仅指full adopted（已存在 `adopted_claim_ids` 对应真实claim），partial/rejected/合法排除不算；归侧优先speaker_key→stance→speaker，冲突/未知单列而非推断同侧。claim_id须真实存在，且模型明确引用，不能只因账本里有同侧claim即算对齐。

| 指标 | 分子/分母与缺失处理 |
|---|---|
| 有方向对齐率A | 存在≥1个“明确引用∩full adopted∩真实claim∩同侧”的BULL/BEAR档数 / 原始BULL/BEAR档数；错误ID、反侧引用、未采纳、未知侧、无引用都为不对齐；分母0为NA而非100% |
| 方向账本存在性对齐A_exist（辅助） | 原始方向有≥1个同侧full adopted，不要求明确引用；不能替代A，用于区分模型是否真的引用 |
| 同分母不对齐产出U | 不对齐BULL/BEAR档数 / 全预注册股票日数；与A共同报告，避免条件分母变化误导 |
| 同分母对齐方向产出J | 对齐BULL/BEAR档数 / 全预注册股票日数；失败/缺失/中性贡献0，防止全判中性得到虚假高对齐 |
| 多空中性分布 | 每状态数/全预注册股票日数，同时报完成且可解析子集分布、状态迁移矩阵；全状态比例和为100% |
| 短线偏空占比B | BEAR数/全预注册股票日数为主；另报BEAR/(BULL+BEAR)，方向分母0为NA。不可把旧75%有方向分母与新全样本分母比较 |
| 原始有方向覆盖C | 原始BULL或BEAR数/全预注册股票日数，包含不对齐方向；另报门后有效方向覆盖，避免错把原始覆盖当最终可执行率 |
| 中性处置合规（机制） | 原始full adopted两侧均无可用论点的可解析档中，NEUTRAL数/该子集总数；0分母为NA。未采纳同侧却给BULL/BEAR列违规清单，不能强制改为NEUTRAL再统计 |

该约束要求“输出方向须有同侧引用”，不要求账本有论点就一定给方向。有同侧论点仍判中性可合法，但会降低覆盖，交由非劣保护检测。引用论点事实是否正确另作审核，不以本结构对齐率证明事实正确。

指标按N−O报告pp及CI，短线为主效应，**短线和中线覆盖均受非劣保护**，中线方向分布与对齐另报、不宣称短线效果可迁移。各臂账本侧别和支持桶（bull_only/bear_only/both/no_support/partial_only）另列，可回查“bull_only→BEAR”，不得按处理后的桶换样本或把不同桶当随机可比子群。

## 5. 预注册判据与200对确认档结论强度

以下效应阈值/非劣界为**项目评估师建议，待总控冻结批准**；处理方向已由总控裁定。不能宣称这些门已取得结果。

- 对齐：短线A提升点估计≥10pp，N侧A≥90%；A分母为0或不可估即不通过。若O侧A已≥90%，则预注册改用“维持高对齐，未证改善”解释，不事后放宽10pp门。
- 非空转：短线J差点估计≥0；短线U下降点估计≥5pp。避免全方向转中性后U下降却没有对齐输出。
- 短线偏空：B下降点估计≥5pp；有方向子集BEAR占比同时报告，但不要求达到50%，也不强求BULL增加。BEAR→NEUTRAL是预期机制之一，只有覆盖保护通过才可称受控修正。
- **覆盖非劣界：每档C_N−C_O>−10pp，采用日期聚类单侧95%下界>−10pp判非劣成立。** 绝对10pp为容忍上限，不是允许每份报告损失10%；例如O覆盖60%，N至少需高于50%且下界过门。另报门后有效覆盖同界，若仅原始覆盖通过但门后明显损失须报总控，不放行上线。
- 运行有效性/双身份：全部计入对照结论的样本通过P3隔离、B3双身份、同输入与同实际模型核验；运行完成率N−O和缺失率明示。发现串扰、双身份丢失、未来数据或供应商不明，停止新增调用并保存台账。

**200对确认档**：全部点估计门、两个档位覆盖非劣下界及身份有效性必须通过。点估计符合但覆盖CI跨−10pp，结论“方向性支持，非劣证据不足”，不得以p>0.05当非劣；A/偏空变化小于预设实用效应或无法估计，报未支持/证据不足，不解释成效应不存在。除上述点估计门与覆盖保护外，短线A差的双侧95%CI下界>0、U差CI上界<0、B差CI上界<0、J差单侧95%下界>−5pp，且日期簇≥30、完整有效配对达到批准目标，方可报“在本历史样本框中有统计支持的流程修正”。多个必要门全过才联合成立，不能挑其中显著项。仍不等于准确率提高、能赚钱或生产合入授权。

## 6. 样本量与功效依据

n是股票日配对数量，两档不可将n翻倍。二元变量配对差D∈{−1,0,1}，不一致率q=P(|D|=1)，净效应delta；独立方差为(q−delta²)/n。双侧alpha=0.05、单指标80%功效规划近似：

`MDE ≈ 2.802 × sqrt(q × DE / n)`，`DE=1+(m−1)rho` 为规划敏感性而非实测。用于U/J/BEAR/覆盖等同分母二元变量；**A是两臂有方向子集的条件比率，不能直接套用n的McNemar MDE**。其功效需方向样本量/配对缺失/基线对齐证据，目前未测量。

| n | q假设 | DE假设 | 双侧MDE |
|---|---|---|---|
| 200 | 0.30 | 1.0 | 10.9pp |
| 200 | 0.30 | 1.5（每日5只、rho=0.125） | 13.3pp |
| 200 | 0.50 | 1.5 | 17.2pp |
