## 1. P0-2：正式信号日的基率口径

依据冻结计划 `dav2142-phase1-preregistration-v0.2.md` §2.4：**W0 是“截至预测时可知成熟标签的扩窗，历史来自 P1 全市场”。正式信号日的基率，用冻结 P1 面板 `p1-base_t10-frozen/` 中按原成熟规则截至该日已可知的全部成熟合格标签计算。**

**“成熟合格标签”**指冻结面板中同时满足以下条件的行：

> `outcome_status == evaluated_ok` **∧** `universe_ok`（**非北交所**、**信号日非 ST/\*ST**、**上市 ≥60 日**）**∧** `y_rel` 非空 **∧** `actual_exit_date` 为**合法 8 位交易日**；
> **`pending_due`、`data_missing`、`suspension`、`unexecutable_entry` 不进分子分母**。

该过滤沿用 P1 既有分母口径（`docs/research/phase2-midterm/chunk-build.md:75-76`；实现 `scripts/phase2/m1_base_rate.py:116-119`），本附表不重新定义。按此口径只读复算冻结面板，成熟合格标签合计 **9,244,318 条**，其中跑赢行业的标签 **4,266,673 条**，**`p_market = 0.461545`**（保留六位小数）。

对每个正式信号日 T，保持同一冻结面板、同一标签资格及成熟规则、同一 m200/W0：

- 查询日范围照录 DAV-2240 实现 `base_source["query_days"]["scope"]["rule"]`：**query days = 正式 cohort 信号日 ∪ admit 输入行中标签未到期（r 为空）的待评信号日（DAV-2240）**。查询日可以晚于面板末日，不能因为面板中没有该信号日而直接判为无基率。
- 行业与市场计数均取该冻结面板中截至 T 的预测时点已可知的成熟合格标签；退出日晚于该时点成熟截点的标签不计入。本冻结来源成熟日上界 `mat_upper = 2025-12-31`，严格早于所有正式查询日（≥ `2026-10-08`），故 §2.4 的 `as_of` 时刻分支（≥ T 日 15:00 / < T 日 15:00 仅纳入 ≤ T−1 / `as_of` 不明则不可判定）**在本冻结来源上恒为空操作**。**该分支目前在基率引擎中尚未实现；引入面板之后的新标签前必须先补实现。**
- 沿用 `q_base,j,T=(s_j,T+200*p_market,T)/(n_j,T+200)`，其中 `p_market,T=s_market,T/n_market,T`，n 为成熟合格标签数、s 为其中跑赢行业的标签数。W0 不设置滚动回看窗，也不表示引入冻结来源以外的新标签。
- 缺行业、缺历史或缺来源证据时，沿用原缺失判定及实现理由码；不填零，不以市场常数补出行业基率，不以 P4 自选样本估计基率。

上述登记澄清的是正式信号日如何查询冻结历史，保持冻结计划的统计公式及成熟规则。
