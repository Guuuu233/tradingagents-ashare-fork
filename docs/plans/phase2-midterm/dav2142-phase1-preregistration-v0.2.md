## 3. 统计量与公式

所有日横截面为信号日×版本×期限，过滤后不同股票数n_t；n_t<10记insufficient，不补0。秩方差为0记rank_degenerate。真实交易日缺口保留NA。

### 3.1 两条概率证据线（分别计算，不混合）

1. **IC**：`IC_t=corr(rank_avg(q_i,t),rank_avg(r_SW,i,t))`。`mean_IC=sum(IC_t)/D`，D为有效日数，日等权。秩退化不记零。
2. **五分位**：对第k箱，a=(k-1)n_t/5，b=kn_t/5；L_i为严格更低概率数、E_i为同概率数，`w_ik=max(0,min(L_i+E_i,b)-max(L_i,a))/E_i`。`Q_k,t=sum(w_ik*r_i,t)/(n_t/5)`，组差`Delta_t=Q_5,t-Q_1,t`，日等权汇总；披露边界并列只数/权重，不解释为可成交组合。
3. **Brier**：`BS_t=sum((q_i,t-y_i,t)^2)/n_t`，报告日等权均值。可靠性固定[1–10]、[11–20]…[91–99]十箱，箱内逐股票观测等权：预测均值、y均值、二者差、行数、不同股票数、日期数。沿既有实现，只用n_t>=10且非退化有效日；空箱NA而非0，不事后合箱；校准仅描述，不宣称逐行二项置信区间有效。
4. **D-075增量**：同日先取q、r、q_base均有效交集，交集n_t>=10且两腿IC均可定义。重新计算两腿IC，`dIC_t=IC_model,t-IC_base,t`。均值和推断仅取共同有效日；不直接相减两条覆盖不同日期的汇总IC。缺基率记录两侧都不用，漏斗列model_rows/paired_rows/no_base_rows/paired_day_n。并列给模型/基率IC、五分位、可靠性；全样本模型结果另列，不能冒充配对结果。辅助 `dBS_t=BS_model,t-BS_base,t`（负为模型更好），仅在相同交集描述。
5. **分布/工程诊断**：唯一概率数，最大频率占比`max_v n_v/N`，熵`-sum(f_v ln f_v)`，每方向均值/标准差/唯一值；失败/无效率=`(missing+malformed)/完成的目标档分析单元数`，node_failed/not_run分别列。M1工程20×2若另有获准实测，重复诊断`C=sum((q1-mean(q1))*(q2-mean(q2)))/(m-1)`、`A=sum((q1-q2)^2)/(2m)`；不是本次开跑授权，m约20时C<=0不是硬否决。

### 3.2 日序列推断与多重比较

对任一日级序列x（IC、配对dIC、辅助组差），保留完整计划交易日槽，无效槽NA。有效日D，`mu=sum_valid(x)/D`，`u_t=x_t-mu`（缺失槽贡献0），`gamma_k=sum_valid_pairs(u_t*u_(t-k))/D`。

`V_L=[gamma_0+2*sum_(k=1..min(L,S-1))((1-k/(L+1))*gamma_k)]/D`，S为交易日槽数，`SE_L=sqrt(max(V_L,0))`。L固定60/120；区间`mu ± 1.959964*SE_L`，95%双侧。D<3不报推断；SE为0、非有限或协方差异常时只报点估计并记不可判定，不用零标准误制造显著。不得按股票行IID，不用简单报告数/40推信息量。

**一次确认族F只含活跃1883队列两项**：F={1883-T10平均IC=0、1883-T10平均dIC=0}。M1两项移出，启动前另立预注册，**不用p=1占位**。每项计算两带宽双侧正态近似p值 `p_L=2*(1-Phi(abs(mu/SE_L)))`，稳健p取`max(p_60,p_120)`。活跃项若本次不可估则原p=null并标不可判定；调整时其保守计算占位为1，两项族大小不因缺数缩减，但这不代表为M1保留名额。

F采用Holm逐步法，按p从小到大排序，第j项阈值`0.05/(2-j+1)`（依次0.025、0.05），首次未过即停止拒绝后续；等价报告`p_adj,(j)=min(1,max_(k<=j)((2-k+1)*p_(k)))`。**族错误率目标FWER<=0.05，基于HAC渐近p有效的前提，不声称有限样本精确控制。** 正向能力声明还必须mu>0、D>=60、两带宽原95%下界均>0、Holm调整p<=0.05及数据/覆盖合格。基础C门通过但Holm未过，原始C条件与“确认未通过”分栏，不夸称确认能力。

不对NW60/120各自挑好结果。五分位、Brier、可靠性十箱、参数敏感性、方向/风格归因均**描述性/探索性**，不纳入确认拒绝族，不使用“显著/已证明”措辞或挑单箱p值宣传；若以后要确认风格归因，须另行在新样本前预注册。负向结果如需确认也经过同一双侧Holm，不因方向不利隐去。版本/期限不额外扩检。

### 3.3 风格归因（诊断）

两期限分别按看多/看空/中性报告；缺方向另列，不反推方向。组内每日均值`m_g,t^b=sum_(i in g)(r_i,t^b)/n_g,t`，b为HS300/SW；汇总为有该组日期等权均值，不把所有行摊平。看空收益不翻号。组间诊断对比看多-看空、看多-中性、看空-中性，必须同日两组都有观测，报告共同日期与两侧n。

T日可得暴露：规模=流通市值在T日P1合格全市场股票池的平均秩分位`(rank_avg-0.5)/N_T`；动量=`P_qfq(T收盘)/P_qfq(T-20交易日收盘)-1`，只适用于收盘后信号，收盘前须按已冻结可得时刻截断；行业=T日申万一级成员。市值/复权历史、成员或可得时刻无法核验即该项缺失，不用当前值回填。报告各方向均值/标准差/中位数/Q1/Q3、行业占比；行业占比按同组逐日占比再等权。披露因子有效n、因子缺失分布及点时股票池覆盖。

共同控制诊断：每个信号日对有完整因子且两侧方向存在的样本，分别拟合 `r_i,t^b=alpha_t+beta_B,t*1(看多)+beta_S,t*1(看空)+gamma_t*规模分位+eta_t*动量+行业哑变量+epsilon`，中性为参照，行业哑变量固定去掉编码字典序首行业。OLS等股票权重；要求n_t>=10且n_t>=参数列数+5、设计矩阵满秩，各参与对比组至少2只。缺组/共线/自由度不足记该日不可估，不自动合并行业。组差调整前后在**同一完整因子股票集合、同一有效日期**比较，保留共同日期日序列，不把不同覆盖的系数相减。

调整前后差值仅描述。可附 `1-|调整后组差|/|调整前组差|` 作衰减比例，但原差为0或正负反转时置NA并标记；不设事后“衰减超过50%=主要来自风格”阈值。观察性关联、暴露测量误差和未控制因子不能支持因果占比。即使出现衰减，也只能称“与所测风格暴露一致”，不能直接回答因果意义的“主要来自”。本项不冒充M1已签收的规模/估值/动量/波动四因子残差IC；后者仍属M2诊断实现范围，缺因子不擅自换成三因子。
