## 1. 评估对象与结论边界

**评估结论：有条件可行（草稿评估时）；本口径已签收定稿。** 两项冻结口径可直接落实到日级评估；M1 工程验收与到期后的统计能力评价必须分开。解析无效率上限、读数节点、推断参数及计算细则已由总控裁定（附录 1–9），执行时以签收值为准，不得再按草稿建议值或自定值执行。

### 1.1 契约对象

M1 的对象是中线概率契约 `b2.v1` 的 `p_rel_t40`：整数 1–99。记归一化概率为 `q = p_rel_t40 / 100`。其语义照计划 §5：

> P(股票从 T+1 开盘到 T+40 收盘的收益 − 同窗口申万一级指数收益 > 0 | 截止时合法信息)。

- 中线档才是该字段的目标档位；短线 `p_rel_t10` 不能改名或当作 T+40 概率。既有中线报告中的 T+10 概率也不进入本稿主序列。
- 方向与概率是两个输出维度。不得由看多/中性/看空硬编码概率，不要求用 50 或其他阈值反推出方向；同一方向允许不同概率。
- 方向字段、档位字段的实际名称和枚举沿用 DAV-1450 定稿及契约，不在本稿臆造接口字段。中性或风险层拦截不自动排除有效的中线概率信号。
- `p_base_rel_t40` 是代码另存的行业历史收缩基率，不给模型看。它用于基线比较，不取代 `p_rel_t40`；概率融合属于 M3，不能在 M1 评估中默默替换原始概率。
- 代码 SHA、提示词哈希、响应中的实际服务模型、契约版本共同构成版本键。不同版本分队列；不能只凭配置中的模型名认定同版本。

### 1.2 两条证据线

1. **M1 工程与重复测量线**：字段合法、读数到达、持久化、隔离、输出不塌缩；按计划至少 20 只股票 × 每只 2 次冻结输入重复运行。此处只是未来验收要求，本次没有执行。
2. **到期预测评价线**：对成熟且合格的 T+40 标签计算日级 IC、辅助组差、校准及诊断，衔接 M2/§6。工程合格不代表已证明排序能力；正 IC 或正组差也不代表扣成本后能赚钱。

## 2. 样本、窗口与纳入规则

### 2.1 T+40 与收益标签

设信号交易日为 T：

- 标准预测入场：T+1 交易日开盘；标准退出：**从信号日起偏移 40 个交易日的 T+40 收盘**。不是 T+1 再持有 40 个交易日，也不是 40 个自然日。
- `return_labels.py` 经 P2 统一后的标签是唯一结算真相源；评价端消费其日期和类型化结果，不能另算一套退出日。
- 行业按分析日调用 `resolve_sw_l1_benchmark(symbol, analysis_date)`，不是用今天的归属回看历史。行业收益必须与股票使用同一入场/退出窗口。
- 预测口径（标准窗口）、执行口径（实际退出及同步行业窗口）、研究口径（T 日收盘起算）分开存、分开报。停牌顺延等执行处理不能把主预测目标偷偷改成另一窗口。
- 一字板不可入场、停牌、退市、缺价格、缺行业基准等，沿用 P2 的类型化标签及其纳入规则。标准预测标签若无法成立，明确记原因，不填零、不拿实际延期收益顶替。可纳入的结算状态、复权/分红规则以 P2 交付（DAV-1479 等）为准；本文件不重新定义它们。

对 P2 批准的同口径价格或收益序列，记：

```text
R_stock(i,t) = P_stock(exit) / P_stock(entry) - 1
R_ind(i,t)   = P_ind(exit)   / P_ind(entry)   - 1
r(i,t)       = R_stock(i,t) - R_ind(i,t)
y(i,t)       = 1{r(i,t) > 0}
```

`r = 0` 对应 `y = 0`，不算跑赢。收益以小数表示；展示时可换算为百分点。这里定义概率目标的行业相对收益，不把交易成本、风格回归残差或沪深300 超额收益塞进 `y`；那些是分列的诊断/组合指标。价格调整的细节由 P2 冻结，不凭本稿自行选定。

### 2.2 横截面构成

- 横截面以**信号交易日 T × 版本键 × 标准预测口径**分组，按不同股票计数，不按报告份数、重复次数或到期日拼组。
- M1 的 20×2 用于重复测量，不自动成为 40 个独立预测样本，也不要求已有 40 日后结果。
- M2 按计划使用沪深300与中证500的当时成分，排除 ST、次新、停牌，按行业分层随机抽样；每日 N 由 P1 信息量—成本前沿决定。冻结的 10 是**过滤后有效样本门槛**，不是把 M2 采样预算固定为每日 10 只。
- 第一阶段固定 48 只、A/B 隔日轮换的测量批只能按其真实来源单列；不改配置、不与新中线队列混算，也不把历史回填包装成正式前瞻成绩。

### 2.3 正式成绩纳入条件

一条样本进入正式主序列前须同时满足：

1. 中线 `b2.v1` 目标输出，`p_rel_t40` 为合法整数 1–99，读数与封存持久化可核对；不以 50 或方向映射补值。
2. `timing_class = F0` 且 `input_pit_status = VERIFIED`，封存及版本证据完整。
3. T+40 标准预测标签已成熟，股票收益与当时行业同窗口收益均有效。
4. **主运行去重（已签收）**：同股、同日、同版本取 `created_at` 最早的已完成运行，事前固定，不得看结果后挑表现最好的一次；重复平均只作为 M3 候选策略。

其余样本按计划分流：F0 + UNVERIFIED 只研究/管线诊断；F1 只研究；H 只调试；`input_pit_status = FAILED` 一律不进。未到期是未成熟，不是错误标签，不按零收益计。

每个日期保留抽样数、尝试数、合法概率数、到期数、有效配对数、各排除原因及最终 `n_t`。不因方向、概率大小、收益符号或风控 BLOCKED 而事后筛选主横截面。缺失造成的覆盖偏差必须另报；不能把删除失败样本后的统计当作管线无失败。

### 2.4 单日状态

- `n_t < 10`：精确记为 **`insufficient`**，不计算/不纳入主 IC 日序列；可以单列覆盖情况，不能记为 IC=0。
- `n_t >= 10`：达到数量门槛，再检查指标是否可定义。概率或收益的秩方差为零时，IC 不可定义，单列为“秩退化”（诊断标签建议，不声称是现有代码枚举），不记零、不混称 insufficient。
- IC 可定义且标签等纳入条件满足：进入该版本的主日序列。数量门槛必须在全部纳入过滤后检查，不能用抽样原始份数替代。

## 3. 指标定义与计算式

### 3.1 主指标：日级 Spearman 排序 IC（已冻结）

对合格日期 t 的 n_t 只股票，以平均秩处理并列：

```text
a(i,t) = rank_average(q(i,t))
b(i,t) = rank_average(r(i,t))
IC_t   = Σ_i [(a(i,t)-ā_t)(b(i,t)-b̄_t)]
         / sqrt{Σ_i (a(i,t)-ā_t)^2 × Σ_i (b(i,t)-b̄_t)^2}
```

- 概率整数离散导致的并列是正常情况，不能随机抖动概率或按方向拆出假精度。收益并列同样用平均秩。
- `IC_t > 0` 表示当日概率较高者倾向有较高行业相对收益；`IC_t < 0` 表示反向排序。
- 无并列时才可用 `1 - 6Σd_i²/[n_t(n_t²-1)]` 简式；有并列时用上式，不能直接套简式。
- 主汇总为各有效交易日等权：`mean_IC = Σ_t IC_t / D`（已签收）。不能把所有股票/报告摊平当成独立样本。大横截面日加权结果如另报，须标辅助且不可替代主结果。
- 保留真实信号日期及无效日期清单；做时间相关推断时不能压缩缺失日期，假装缺口两端是相邻交易日。

### 3.2 辅助指标：高低五分位组差

主横截面按 q 从低到高分为五分位；比较最高 20% 与最低 20% 的行业相对收益均值：

```text
Δ_t = mean(r | 最高概率五分位) - mean(r | 最低概率五分位)
```

**并列及 n_t 非 5 倍数的处理（已签收）**：用边界并列等比例分配权重，避免按股票代码任意拆并列。令 `h = n_t/5`；对股票 i，`L_i` 为概率严格小于它的股票数，`U_i` 为严格大于它的股票数，`E_i` 为与它同概率的股票数（含自身）：

```text
w_low(i)  = min(max(h - L_i, 0), E_i) / E_i
w_high(i) = min(max(h - U_i, 0), E_i) / E_i
Δ_t       = [Σ_i w_high(i) r(i,t) - Σ_i w_low(i) r(i,t)] / h
```

两尾权重各合计 h；n_t=10 时每尾相当于 2 只。边界并列可贡献分数权重，须披露涉及只数及权重。它是统计分组，不是可成交组合，也不暗示买卖空头可执行。若概率全相同，分组差可为零，但须与 IC 不可定义、概率塌缩诊断并列披露，不能作为“正常排序”的证据。

Δ_t 及其日均值仅作辅助；不能因 IC 不好而改用组差成为主指标。小于 10 的日期也不进入正式辅助组差序列；如研究性展示，必须单列并标不足。

### 3.4 M1 重复运行诊断

在 m≥20 个同输入配对、每个 2 次独立实验线程的样本中，分别取 `q_i1`、`q_i2`。建议报告：

```text
稳定成分估计 C = Σ_i(q_i1-q̄_1)(q_i2-q̄_2)/(m-1)
重复差异平方半值 A = Σ_i(q_i1-q_i2)²/(2m)
```

C 是交叉乘积协方差估计，不是相关系数；A 是差异诊断，不在条件未核实前宣称是纯随机噪声方差。必须核实冻结输入、实际服务模型一致、独立检查点/线程等，模型或版本改变不能混入同一重复对。

计划明确：20×2 规模下 C≤0 只表示“未辨认出稳定成分”，不能证明稳定成分不存在，也不构成工程硬失败。概率集中度、熵、方向内离散度不另设未经批准的硬阈值。20×2 也不能替代成熟横截面及 §6 的时间相关推断。

## 4. 判定标准及与计划 §6 的衔接

### 4.1 M1 工程硬失败与管线状态

计划 §5 的原清单如下，任一出现即不上线、修复后重测：

1. 字段缺失或解析无效率超过上限；
2. 概率没有到达指定读数节点或没有持久化；
3. 运行串扰；
4. 概率是方向的确定性映射（同一方向只出现单一取值）；
5. 不同输入输出同一常数。

验收报告应列各项证据、分母及失败数。**解析无效率上限（已签收）**：M1 重复测量 40 次尝试中解析无效不超过 1 次；上线后滚动 5 个交易日，中线档解析无效率不超过 2%，分母 = 中线档完成的分析单元数。**读数节点（已签收，三处都要核到）**：研究经理中线输出 → 报告 `medium_term` 持久化 → P4 封存账本；具体键路径由 M1 实现卡写定并写入验收报告。证据缺失时记“验收条件未齐/待验证”，不写通过。对方向映射/跨输入常数，要展示输入及每方向取值表；只有一次观察的方向不足以辨认映射，应明确检查覆盖不足，而非臆测无问题。

- **管线正常（有限含义）**：字段、节点、持久化、账本、版本、标签及缺失分流已按签收规则核对，重复运行工程证据齐全，未触发硬失败。它只说明工程工作正常，不表示模型有预测能力。
- **样本不足**：日 n_t<10 按冻结规则记 insufficient；到期日序列不足或独立窗口/市场状态覆盖不足时，可以管线正常但统计结论仍不足。两个维度不得互相替代。
- **硬失败**：按上述清单处理，不因少数漂亮 IC 或组差抵消。反之，尚无可证明的正 IC 不能擅自变成 M1 工程拒绝上线阈值。

### 4.2 日序列推断

主结果是单版本的 `{(t, IC_t)}` 日序列，再对均值作**能覆盖 T+40 窗口重叠的时间相关稳健区间**。HAC 或移动块自助由 P1 按实测自相关确定并冻结；本稿不把带宽/块长武断填成 40，不改用股票行 IID、普通二项检验或按报告份数计算标准误。

**推断配置（已签收）**：日 IC 序列用 Newey-West HAC，主带宽 60，稳健性带宽 120（与 P1 裁定③一致），95% 双侧；真实日期缺口不压缩，保留无效日期清单；最少有效日期与 C 档门槛见 §4.3。

IC、组差、校准与风格调整结果分别列示；不能看到结果后切换主指标、推断方法、窗口或样本来源。有效独立窗口数由 P1/P2/M2 的实测相关结构估算，不以“报告数/40”或“交易日数/40”直接当作已识别的信息量。

### 4.3 结论强度分档（已签收）

| 档 | 前提 | 可以说 | 不可以说 |
|---|---|---|---|
| A：工程/管线档 | M1 工程证据已核对；尚无成熟充分序列 | 契约、标签管线是否正常；若证据缺失写待验证 | 有排序能力、校准准确、能赚钱 |
| B：描述性档 | 已有合格到期日期，但推断或有效信息量/状态覆盖不足 | 报告 IC、组差方向与覆盖；首批到期仅看管线及明显梯度 | 把点估计正值当作已证明能力 |
| C：有限统计证据档 | **已签收门槛**：有效日期 ≥60，且 NW60 与 NW120 的区间下界都 >0；报告区间与状态覆盖 | 满足时可表述为“在本版本、该样本及市场覆盖范围内存在正排序证据”；达不到只报 A/B 档 | 对未覆盖行情外推；把统计排序证据当可交易净收益 |
| D：版本/运营扩展档 | 有充分同日同股配对与覆盖；组合另满足 M2 真实规则和成本记账 | 版本配对或组合的相应受限结论，逐月更新强度 | 用满三个月自动升级；挑最好挑战者或跨模型混算 |

区间跨 0 表示证据不充分，不等于证明能力不存在；若整个区间小于 0，应报告负向排序证据。C 档门槛按上述已签收值；D 档的同日同股配对与组合证据要求按 M2/M3 卡执行。计划中“首批约 12 月初”“约 3 个月可开始版本比较”是条件性排期，不是自动统计通关线。

版本比较必须在同日同股交集上，分别计算两版 IC，再对 `IC_new,t - IC_old,t` 的日序列作时间相关稳健推断；交集过滤后仍须 n_t≥10。完整各版成绩另报，不能用两个不同股票集合的 IC 差冒充配对结果。挑战者、配对指标及升级门槛按 M3 事前写定。

“能不能赚钱”留给 M2 影子组合：成本、A 股可成交约束、换手、回撤、风格调整前后及廉价替代策略对照。排序 IC、组差和 Brier 都不能单独替代这项结论。

## 6. 风险清单与优化建议

### 6.1 风险（按严重程度）

1. **高：把缺失或变更窗口的收益当正常标签。** 会改变概率目标；须先完成 P2 标签/行业腿签收，类型化排除并披露分母。
2. **高：把重叠窗口及重复运行当独立报告。** 会高估信息量；按信号日统计、股票去重、版本分队列，用 P1 冻结的时间相关推断。
3. **高：M1 工程门与统计证据门混淆。** 不能以噪声估计≤0否决工程，也不能以工程通过宣称盈利。
4. **中：概率并列、边界分组或风格暴露产生误读。** 用平均秩，签收分组规则，风格调整与原始结果并列。
5. **中：执行口径误用。** 解析无效率上限、读数节点、推断带宽、分箱及 C 档门槛已签收固定；实现若偏离签收值（如改带宽、改分箱、放宽无效率上限）即为口径违约，不能出正式通过或优胜结论。

### 6.2 执行路径（口径已定稿）

- **P0：按签收口径实现 M1。** 解析无效率上限、三处读数节点、平均秩、日等权、日期缺口、主运行去重、五分位分数权重、秩退化单列均按附录签收值执行；实现卡写定 `medium_term` 持久化与账本的具体键路径。
- **P1：M1 验收报告分为工程表、概率分布诊断、20×2 重复诊断、到期统计四节。** 每项注明是否已测、证据版本、未测原因；本文档不代替实测。
- **P1：推断按 NW-HAC 60/120、95% 双侧执行。** C 档须有效日期 ≥60 且两带宽下界都 >0；达不到只报 A/B 档。
- **P2：到期后沿用正式/研究/调试分队列。** 正式只收 F0+VERIFIED；首次到期只出管线及描述性结果，满足后续门槛再提升结论强度；可靠性固定 10 箱，风格中性化按 P1 四因子日内截面残差实现（归 M2 卡）。

**路径推荐**：口径已定稿，按附录签收值完成 M1 的独立工程验收；成熟的日级评价渐进接入 M2。不要提前开模型、触碰生产、修改第一阶段批；本文档不含真实样本测量结果，也未声称任何 M1/M2 条件已满足。
