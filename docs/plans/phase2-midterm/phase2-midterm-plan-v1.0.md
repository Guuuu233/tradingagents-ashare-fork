## 0 摘要

- **研究重心**（David 10-04）：提高准确率、判断能不能赚钱，不做论文式确认。中线 T+40 为主，短线 T+10 降为辅助诊断。
- **主问题**：同一天里，系统更看好的股票，T+40 行业相对收益是否更高？扣除成本、扣除风格暴露之后，按它构建的组合是否跑赢便宜的替代品？
- **结构**：
  - 预备期：现在到第一阶段验收，只读、不调模型或少量调用，不碰生产输出；
  - 正式期：三个里程碑，依次是 M1 中线概率契约、M2 前瞻模拟实验室、M3 挑战者机制；
  - 之后持续运营。
- **时间**：
  - 第一阶段出口最早 11 月下旬（H1b 日历门槛：第 30 个交易日约 11-19，第 45 个自然日约 11-22）；
  - 正式期最早 12 月初开工；
  - 每日测量批 10-08 起产出的中线样本，约 12-03 开始逐日到期。
- **对第一阶段的承诺**：预备期不修改研究经理输出契约，不改每日测量批的配置和股票池，不在生产上发起额外批量。

### 1.4 已知缺口

1. **三套收益口径不一致**：
   - `p_rel_t10` 的提示词从 T 日收盘起算；
   - `return_labels.py` 在信号日起第 N 个交易日退出（`return_labels.py:307-308`）；
   - V-03a 在 T+1+N 日退出（`v03_return_measure.py:2261`），基准是沪深300。
2. **行业基准腿缺失**：没有申万行业指数的收益计算，代码里从未调用过 `sw_daily`。
3. **运行隔离**：类级共享检查点存储（`trading_graph.py:218`），加上不传 thread_id 时的确定性默认线程名（`trading_graph.py:692`）。同进程重复运行同一机会时有串扰风险；API 路径不受影响。
4. **中线没有概率输出**。
5. **测量批的股票池不适合中线横截面评估**：48 只固定大盘股、隔日重复，同一只股票的 T+40 窗口大量重叠，有效样本远少于份数。

## 2 目标与边界

**要回答的问题**（优先级从高到低）：

1. 中线排序能力：同日横截面上，概率或方向更高的股票，T+40 行业相对收益是否更高？
2. 校准：说 70% 的事，是否大约 70% 发生（L3 统计诚实）？
3. 组合层面：扣成本、扣风格之后，影子组合是否跑赢沪深300、简单因子组合、系统自身基率等便宜替代品？风控层用多少收益换来了多少回撤改善？
4. 版本升级：新版本在同日同股上是否稳定优于旧版本？

**不做**：

- 第一阶段期间不改研究经理的输出契约，也不改测量批。
- 不删除短线；短线保留为辅助诊断，用来回答"市场是否立刻认可这个逻辑"。
- 不追求跨三年冻结模型的确认性结论。换模型就切版本队列，分开记账。
- 本阶段不做强化学习或在线自我改写提示词。

## 4 预备期（现在到第一阶段验收；只读或零模型，不碰生产输出）

### P1 历史结构研究（零模型）

- **数据**：`sw_daily`、个股日线、每日指标；当时的申万 2021 归属；样本包含已退市股票。
- **产出**：
  - T+40 行业相对结果在同一窗口内的相关系数，按全体、同行业、同风格分别统计；
  - 风格暴露（规模、估值、动量、波动）对行业相对收益的解释力；
  - 分行业的历史基率及其波动；
  - 按日横截面口径估算：模拟盘要跑多久、每日要多少只股票，才能判断有没有超额；
  - **信息量—成本前沿**：比较每日 N=10/20/30/40 时的年新增有效信息量、token、费用、延迟、行业覆盖和排序精度。一份双档约 130 万 token，N=40 约每日 5200 万 token，不默认接受。M2 的 N 按"边际信息增量 / 边际成本"定；
  - 冻结 §6 推断所用的具体方法（HAC 带宽或移动块长度），依据是实测的自相关结构；
  - **两项须在 M2 正式结果暴露前冻结的产出**：`primary_cross_sectional_metric`（倾向日级 Spearman 排序 IC 为主、高低分组差为辅，按实际横截面样本结构裁定）；`min_daily_cross_section_n`（低于该值的日期记为 insufficient，不进主日序列）。
- **验收**：结论来自已提交的脚本（D-036）；不提交行情原始数据（D-040）。

### P2 统一收益口径与行业基准（只做离线部分）

- **裁定**：以 `return_labels.py` 为唯一结算真相源，"T+40"指 T+1 开盘入场、信号日起第 40 个交易日收盘退出。V-03a 改为消费它给出的日期，升版为 V-03b，`hold_days` 改名为 `eval_offset_from_signal`。
- **三种口径分开存**：
  - 预测口径：标准窗口；
  - 执行口径：实际退出日，行业基准同步；
  - 研究口径：从 T 日收盘起算。
- **行业基准**：当时的一级行业（`resolve_sw_l1_benchmark`，DAV-1453 已裁定），取 `sw_daily` 收益。
- **验收**：
  - 合成行情单测；
  - 对已成熟的中线样本（含 D-067 回填，单独标记）出标签；
  - 新旧口径对照。按旧口径算出的历史结论，重算后才可继续引用。

### P3 实验运行隔离

- **原则**：**生产默认行为不动**（不改 `propagate()` 的默认线程名，避免影响既有的检查点恢复语义）；只约束实验路径。
- **内容**：
  - 图可注入检查点存储，实验运行一律注入独立实例；
  - 实验 harness 强制显式线程编号 `{sample_id}:{system_version}:{arm}:{replicate}:{uuid}`，实验模式下若走到默认线程名即报错；
  - 在 `experiment_run_identity` 记录线程编号；断言实验路径不写记忆。（DAV-1486：实验身份改用独立键名，不再复用 API 侧 `run_identity`，避免被 `_attach_traceability_fields` 无条件覆盖）
- **验收**：同进程、同股同日同档连续两次实验运行无串扰（旧路径红、新路径绿）；生产 API 路径行为与 RT-FULL 不变。
- **定位**：作为 DAV-1450 A/B 与 DAV-1455 的共同前置，可在 10-09 前完成。

### P4 封存账本设计，并封存现有测量批输出

- **账本**：只追加、带哈希链；记录版本、截止时间、封存时间、入场时间、结果可知时间。
- **两个正交维度**：
  - 时间等级 `timing_class`（互斥）：
    - F0：封存 < 入场（T+1 开盘）；
    - F1：入场 ≤ 封存 < 结果可知（T+40 收盘）；
    - H：封存 ≥ 结果可知。
  - 输入时点状态 `input_pit_status`：VERIFIED / UNVERIFIED / FAILED（所有数据源时间戳不晚于截止才算 VERIFIED；读不到时间戳记 UNVERIFIED）。
  - 例：国庆期间生成、新闻时间戳尚未核实的预测记为 F0 + UNVERIFIED。
- **预备期做法**：每日对测量批产出做只读快照，记录哈希。不改生产写入路径。

### P5 中线只读周报

- **内容**：对测量批中线结果出周报。指标按以下顺序：
  1. 方向分布；
  2. 同日去均值后的排序梯度；
  3. 行业相对与沪深300 两种口径；
  4. 被拦档与放行档的事后表现；
  5. 风格暴露。
- **定位**：在样本成熟之前先把计算管线跑通；明确标注"样本不足，不下结论"。

**预备期总验收**：P1、P2、P3 合入或签收；P4、P5 能每日或每周自动产出；第一阶段测量无任何扰动（测量批完成率、无效率与基线一致）。

## 5 正式期（第一阶段出口验收后）

### M1 中线概率契约 b2.v1（约 2–3 周）

- **字段与语义**：
  - 中线档新增 `p_rel_t40`，整数 1–99；
  - 语义：P(股票从 T+1 开盘到 T+40 收盘的收益 − 同窗口申万一级指数收益 > 0 | 截止时合法信息)；
  - 与 P2 的预测口径逐字一致。
- **提示词**：示例里不出现具体概率数字；方向和概率是两件事，同一方向可以给不同概率。
- **基率**：不给模型看。代码另存 `p_base_rel_t40`，第一版取行业历史基率并向全市场均值收缩。
- **与 DAV-1450 合并**：如果 1450 已改动研究经理契约，在它的基础上加字段，一次上线。
- **重复运行测量**：至少 20 只 × 每只 2 次，冻结输入，独立线程，使用固定账户。
- **工程硬失败**（任一出现即不上线，修复后重测）：
  - 字段缺失或解析无效率超过上限；
  - 概率没有到达指定读数节点或没有持久化；
  - 运行串扰；
  - 概率是方向的确定性映射（同一方向只出现单一取值）；
  - 不同输入输出同一常数。
- **测量诊断**（写入验收报告，不设硬阈值；与现行 `p_rel_t10` 基线对照，由总控签字时综合判断）：
  - 概率集中度（出现最多的取值占比）、唯一取值数与熵；
  - 同一方向内部的离散度；
  - 重复运行中的稳定成分与噪声（交叉乘积估计；20×2 规模下估计值 ≤ 0 只能说明"未辨认出"，不能证明不存在）。

### M2 前瞻模拟实验室（约 4–6 周，可分批上线）

- **中线测量批**：独立于第一阶段的 H1b 批。
  - 股票池：沪深300 + 中证500 的当时成分，剔除 ST、次新、停牌；
  - 每个交易日按行业分层随机抽 N 只，N 由 P1 的信息量—成本前沿确定（不预设）；后续可加廉价预筛（全市场 → 候选 → 完整分析），属 M2 后续设计；
  - 收盘后跑，T+1 开盘前封存。
- **封存账本上线**（P4 设计），报告完成即入账。
- **多策略影子组合**：同一份封存信号，同时跑三套：
  - 按经理方向或概率下单；
  - 按风控后的最终动作下单；
  - 高置信精选。

  遵守 A 股成交规则：T+1、涨跌停、停牌、100 股一手，成本沿用 V-03a。风控规则是代码派生的，可以在同一份封存信号上离线重放不同版本。
- **确定性日报、月报**：成绩全部由脚本从账本计算。
- **运营 agent 第 0 版**：只能按冻结规则选股、写订单意图、发起复盘；无权写账本或成绩。

### M3 挑战者机制（12 月以后持续）

- **配对**：冠军与挑战者在同日同股上配对运行，按 P2 口径比较。
- **升级门槛**事前写定：
  - 最少到期样本；
  - 配对指标；
  - 不得事后从多个挑战者里挑最好的。
- **首批挑战者**：
  - DAV-1450 的方向形成修正版（若届时未上线）；
  - 基率融合（代码融合 `p_rel_t40` 与 `p_base`）；
  - 跑 K 次取平均；
  - 过程纠错层（证据核查器定位错误，对出错节点做局部返修）；
  - 冻结经验包（F1 协议）。
- **记账**：每个挑战者分开记账；冠军被替换后保留完整历史成绩。另设一条"滚动冠军"净值曲线。

| 1 | 方向命中率 | 诊断，不作主指标（受大盘共同冲击影响，一年只有约 6 个独立的 40 日窗口） |
| 2 | Brier 分数、可靠性曲线、分档命中率 | 校准（L3） |
| 3 | 同日去均值后合并回归的斜率；高低分组收益差 | **核心能力指标** |
| 4 | 影子组合收益、夏普、最大回撤、换手；风格调整前后两套成绩 | 能不能赚钱 |

**推断规则**：

- **主口径**：每个交易日先算一个横截面统计量，得到日序列。主统计量 `primary_cross_sectional_metric` 与最低单日样本数 `min_daily_cross_section_n` 由 P1 裁定，并在 M2 正式结果暴露前冻结（倾向日级 Spearman 排序 IC 为主、高低分组收益差为辅）；低于下限的日期记为 insufficient，不进主日序列；对日序列用能覆盖 T+40 重叠的时间相关稳健区间（HAC 或移动块自助），具体带宽或块长由 P1 按实测自相关冻结。
- 另报风格中性化后的 IC（同日去均值只消掉大盘冲击，消不掉风格冲击）。
- **辅助诊断**：日期固定效应的合并回归。
- 版本比较一律用同日同股配对。
- 正式模拟盘成绩（净值、IC、Brier、版本升级证据）只收 **F0 且 `input_pit_status=VERIFIED`** 的样本。F0 + UNVERIFIED 只用于研究和管线诊断；F1 只用于研究；H 只用于调试；`input_pit_status=FAILED` 一律不进。

**什么时候能说什么**：

- 首批到期（约 12 月初）：只能看管线是否正常、有没有明显梯度。
- 约 3 个月（2027 年 3 月前后）：版本配对比较可以开始下结论。
- "能不能赚钱"：持续滚动评价，不设固定的最低年限。结论强度随"已累积的有效独立窗口数"和"已覆盖的市场状态（上涨、急跌、风格切换、高低波动）"提升；P1 和 M2 按实测相关结构持续更新有效信息量，月报写明当前处在哪一档。

## 7 版本与模型更换

- **版本键**：代码 SHA + 提示词哈希 + 实际服务模型（取自响应，不看配置）+ 契约版本。
- **换模型或改契约**：开新版本队列，旧队列成绩保留；生产模拟盘不中断，记在"滚动冠军"曲线上。
- **代理与角色绑定**：模型经 CPA 代理，角色未绑定时会落到过期档位（DAV-1305）。版本键必须读实际服务模型字段。
